מולם כווקטורי-בדיקה (מפתחות-STEEM/הוחלפו-מאז · HIVE-חיים-ותקופים):

```
key_material = HMAC-SHA256(
                  key    = bytes-from-hex(זרע-64-hex),
                  message = "SAOS-ROT1/<account>/<chain>/<role>"
               )            // chain קטן: steem | hive
WIF = base58( 0x80 ‖ key_material ‖ 0x01 ‖ sha256(sha256(body))[0..4] )   // דחוס, 52 תווים
```
