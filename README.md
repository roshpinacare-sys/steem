```bash
bun install
```

## עקרונות-ברזל

1. **הוכחה או לא-קרה** — כל טענה חייבת txid/בלוק/stateRoot שניתן להביא מחדש מה-RPC הציבורי. `verify_system.cjs` = השופט, `verify15.cjs` = התביעה-החיה.
2. **מפתחות לעולם לא יוצאים מהמכונה** — חתימה מקומית, שידור ישיר ל-RPC, סינון-WIF מהלוגים.
3. **ריבונות-על-מגבלות** — כל חסם-רשת (RC, 5-ops/בלוק, get_transaction-lag, 8192B, tradesHistory-חלון-שימור) נמדד, מתועד ב-`docs/KNOWN_LIMITS.md`, ונעקף במנגנון ריבוני (רוטר-צי בשלבים-נשמרים, סריקת-בלוק, צ'אנקים, fallback-RPC).
4. **ערך-מכל-תזוזה** — עמלות-צי → בריכה; חתכי-אוצר → `pool_lock`; כל-פעימה → בלוק SAOS-NET.
5. **הכל-בריפו** — `docs/EMPIRE_LEDGER.md` (טבלאות-txids), `worklog.md` (יומן-מלא), `docs/INDEX.md` (מפת-מסמכים). לא-נאבד-מידע.
6. **מחשבה-חדשה-מנצחת** — נרטיב-ישן שנסתר-במדידה מתוקן-בכנות-ומיידית (VERIFY-15: ״הכרטיס צדק — נרטיב-ישן תוקן״).
