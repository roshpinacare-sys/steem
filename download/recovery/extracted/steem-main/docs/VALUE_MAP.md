# VALUE MAP — אבדוקציה: מה יש ביד, מה ניתן להסיק, מה ניתן לאמת

> **הפקודה**: "מה יש לנו ביד? ומה באמת חסר לנו כדי להשלים את התמונה המלאה... היסק-ניסוי בתורת-ההיסק... רשימה רחבה של נקודות שסבירות שניתן לאימות ואיזה ערך הן יתנו לנו... עד איזה גבול נוכל לייצר וליישם חוזים חכמים ומה הם יתנו לנו."
> נכתב ב-Task 61 אחרי שהפלייוויל (A5) עבר מ"פתוח" ל"חי-ומאומת". כל-נקודה: **השערה ← שיטת-אימות ← ערך ← סטטוס מהשרשרת עצמה**. אין-טענה בלי-מסלול-אימות.

## 1. השיטה — אבדוקציה על עובדות-שרשרת

האבדוקציה היא ההיסק ההפוך: לא "מה נכון בתאוריה" אלא **"מה ההשערה הטובה ביותר שמסבירה את מה שכבר הוכחנו"**. העובדות-שביד (מאומתות 2026-09-04):

| עובדה | ראיה |
|---|---|
| 12 זהויות ריבוניות × 2 שרשראות (headcorner + 10 חיילים + ynet posting-level) | keyscan + keyrotate + recovery ×10 |
| הצי מייצר ~1,613G RC/יום (~29K פעולות) | energy_census חי |
| 5,348 SP אפקטיביים לאוצר · 24.94 HP · SWAP.HIVE 2.47 · BEE 0.86 | census + Engine wallet re-read |
| 22 לולאות-דמון חיות (curation נוספה היום), DRY_RUN=false | agent-status |
| 30+ מחלקות-פעולה שהשרשרת מכריזה "שלנו" | get_required_signatures battery |
| מטריצת-הוכחות **92/109** | verify_last.json (ריצה חיה) |
| escrow מלא (transfer→approve×2→release) על-השרשרת | escrow_result.json, txid ×4 |
| חוזה-Engine מבצע מסחר-אמיתי לטובתנו | market.buy BEE התמלא |

מהעובדות האלה מסיקים: **המערכת היא מפעל-חוזים חכמים על-פני-הרשתות** — לא רק משתמשת. השאלה היחידה היא לאיזה גבול.

## 3. חוזים חכמים — עד איזה גבול, ומה הם נותנים

**התשובה-הכנה**: אין על Steem/Hive EVM-חוזים. יש שלוש שכבות-חוזים אמיתיות, ואנחנו חיים בכולן:

### שכבה-1: חוזים-מקוריים של הפרוטוקול (L1-native) — **מוכח**
| חוזה | מה הוא נותן | סטטוס |
|---|---|---|
| escrow_transfer/approve/release | נאמנות בין-זהויות עם בורר | **LIVE** (0.1 STEEM מלא-מחזור) |
| limit_order_create/cancel | מסחר-נזילות | **LIVE** (round-trip) |
| savings deposit/withdraw | time-lock 3-יום | **LIVE** |
| set_withdraw_vesting_route | ניתוב-תשלומים אוטומטי | **LIVE** (lsa→100% אוצר) |
| delegate_vesting_shares | שוק-אנרגיה (HP היא מסילת-האנרגיה) | **LIVE** (ynet +3G RC) |
| convert / collateralized_convert | המרות-מובנות | LIVE (חד-כיווני — ידיעה-שלילית מדודה) |
| claim/create_claimed_account | מפעל-זהויות | **LIVE** |
| change_recovery_account | ביטוח-זהות | **LIVE** ×10 |
| multisig authorities (thresholds) | שליטה-מבוזרת | מובן, טרם-הוקשח (S5) |
| recurrent_transfer (Hive) | מנויים-אוטומטיים | פתוח — דורש יתרה נזילה ≥מינימום |
| חומות-נמדדו | claim_account ~6T RC · create 3 STEEM · 5 custom_json/בלוק/חשבון · 8192B/op · memo 2048B · 40 auths | KNOWN_LIMITS 1–33 |

### שכבה-2: חוזים-שאנחנו הסמכות שלהם (custom_json state-machines) — **מוכח**
- **saos/* spec v58** פורסם על שתי-השרשראות: DEX (pool_init/add/swap/remove — x·y=k, עמלה 30bps), ספר-פקודות, mint/heartbeat, bridge, worldlog (hash-chain seq=55 כרגע), payroll, fleet-ping. **rebuild.cjs מוכיח שהעולם נשחזר מהיסטוריה-ציבורית 11/11** — זו ההגדרה של חוזה-חכם: מצב דטרמיניסטי שכל-אחד יכול לאמת מהשרשרת.
- **מה זה נותן**: עמלות (30bps) נעולות-בבריכה שלנו, נזילות-קבועה (pool_lock), גשר בין-שרשראות, ופנקס-עולם שאי-אפשר לזייף.

### שכבה-3: Hive-Engine — חוזים-אמיתיים של-צד-שלישי שאנחנו מבצעים — **מוכח**
- market.buy התמלא והתיישב בארנק (BEE +0.1 / SWAP.HIVE −0.0581) — אנחנו רוכשים **BEE = דלק-פריסת-חוזים** ב-Engine. הסולם (genesis ladder) צובר אותו אוטומטית.
- **הגבול הבא בר-הישג**: יצירת-טוקן SAOS (100 BEE) ← ואז פריסת-חוזה-עצמאי ב-Engine (deployContract, מונה-BEE) — כאן נולד חוזה-חכם שכתוב-על-ידנו ורץ-אצל-צד-שלישי.
- **מעבר לזה** (מפת-דרכים, לא-היום): VSC (שכבת-חוזים L2 חדשה של Hive), HAF (צומת-מלא עם SQL-על-השרשרת), witness-node (E5) — כולם דורשים תשתית-שרת והחלטות-מפעיל.

## 4. מה באמת חסר לתמונה-המלאה (כנות)

1. **ynet owner/active** — נגזרת של FACTORY_MASTER שאבדה; דרושה הדבקה-אחת בכספת (ה-hook יקים אותו אוטומטית). המפתח שצורף היום (93 תווים) **נבדק מול 12 חשבונות × 2 שרשראות — 0 התאמות** (לא-WIF, לא-גזירה) — הוא לא פותח כלום מהשרשרת-הנוכחית.
2. **witness key + צומת** (E5) — ריבונות-האנרגיה המקסימלית; דורש החלטת-מפעיל + שרת-בלוקים.
3. **100 BEE להנפקת-טוקן** (EC4) — הסולם בדרך; דרוש ~58 SWAP.HIVE.
4. **39 HBD להצעת-DHF** — ערוץ-המימון-הציבורי; המפתח-חי, הדמי-יצירה חומה.
5. **Hive-HP לצי** — Hive רעב-אנרגיה (חיילים 7–12% RC); הפלייוויל בונה גם את זה (E3) אבל לאט; האצה = power-up כשיהיה נזיל.
6. **STRATA + פירוק-מודולים + רפליקה-קרה** — פערי-הנדסה מ-BIG_SYSTEM_PLAN (הקונסולה-נקודת-כשל-יחידה).

## 5. ההחלטה וההוכחה — מה מומש היום (Task 61)

**הדירוג** (ערך÷עלות × בזמינות-היום): A5/E4 ניצח — הוא המנוע שמזיז את כל-השאר (HP↑→RC↑→יכולות↑→גם EC4 קרוב).

**המימוש והראיות**:
- לולאה 22 בדמון עברה DRY_RUN=false + CURATION_ENABLED=true (הדמון כולו חי — 22 לולאות).
- **5 הצבעות אוטונומיות** שודרו בטיק הראשון, **5/5 אומתו על-השרשרת** (active_votes rshares, סה"כ 498,779,272,882 rshares).
- עלות-נמדדה: **2.55% VP להצבעה-מלאה** → קיימות ~7.8 הצבעות/יום — תקציב 5/יום בתוך-הריג'ן; שער-VP 70% נועל את הסוללה מפני-ריקון.
- הקפסולות LOOP-61 + FLYWHEEL-61 נכנסו למטריצה: **92/109** (בדיקת-שלילה: ENGINE-60 חזר לירוק אחרי-תיקון-באג-קריאה אמיתי שהמטריצה תפסה).
- UI: פאנל פלייוויל חי בקונסולה (מצב-לולאה + תקציב + rshares + txid).

**מה זה נותן להמשך**: יעילות (אנרגיה-עודפת מתגלגלת ל-HP במקום להתאדות), ערך (הכנסת-קוראציה יומית מהרשת), נזילות (HP הולך-ונבנה → שוק-האצלות EC5 ייפתח), ריבונות (הצמיחה לא תלויה באף-גורם-חוץ).
