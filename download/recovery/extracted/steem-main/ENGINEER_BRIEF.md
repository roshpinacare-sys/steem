# ENGINEER BRIEF — steem-engeiner · תמצית המהנדס-הראשי

> נכתב על-ידי הארכיטקט/מהנדס-הראשי של הפלטפורמה המרכזית.
> מטרה: להפוך את SAOS מ"מדינה-זעירה על שרשראות" ל**פלטפורמה-המרכזית של הרשת** — על בסיס **Steem · Hive · LEO (InLeo) · Blurt**.
> עקרון-בית שנשמר מהמקור: **הוכחה או לא-קרה** — txid/בלוק/stateRoot מה-RPC הציבורי, או כנות מלאה שזה לא קרה.

## 1. מה יש כאן (הבנת-המצב הקיים — נמדד מהקוד)

### 1.1 שלושת-הגופים במקור (`steem` → שוכפל ל-`steem-engeiner`)

| גוף | מיקום | מה הוא באמת |
|---|---|---|
| **הקונסולה** | `src/` — Next.js 16 + TS + Tailwind + shadcn/ui + Prisma/SQLite | ממשק RTL עברי, 9 מסכים (פיקוד·כספת·כספים·נזילות·ידע·מערכת·רשת·אקספלורר·תוכניות), API-שכבה `src/app/api/**` עם exec-whitelist+cooldown |
| **הדמון** | `agent/agent.cjs` (Node CJS — חובה Node ולא bun: secp256k1 native) | 28–32 לולאות עצמאיות: claim, watcher, curation, dexMm, fleetPace, saosnet, anchor, paymaster, reflex, hivePower, genesis, commandBus, worldlog, fleetSell, liq, valueLock, guardian, cloud-heartbeat, linkage, gitkeeper… |
| **השרשרת-הריבונית** | `sovereign/` — kernel.cjs + saosnet.cjs + genesis + spec | **SAOS-NET v1.3**: מצב=עץ-JSON קנוני, stateRoot=sha256, בלוק כל פעימה, checkpoint כל 12 בלוקים, quorum=3 חתימות-חיילים (custom_json חינם-RC), עיגון Steem+Hive+TRON, kernel-replay מלא בכל טעינה. גובה-חי 495+ |

### 1.2 מפרט-השרשרת (sovereign/spec/CHAIN_SPEC.md) — קבועי-הברזל

- **יחידות**: µ (1 SAOS=1,000µ), µp (מחיר), µlp (מניות-בריכה) — **אסור float במצב**, הכל שלמים, חלוקה=floor, שימור-ערך נבדק בכל swap.
- **ops+גז**: transfer 100 · pay 120 · order 150 · cancel 60 · fill 200 · pool_add 180 · pool_swap 220 · wrap_mint/burn 250 · yield 150 · attest 50 · heartbeat 10.
- **הסכמה**: anchored-quorum — הראש בונה בלוקים, החיילים=ולידטורים חותמים attest על stateRoot, עיגון-צ'קפוינט על השרשראות המארחות.
- **מדידות-חי**: 449K ops/שנ׳ במנוע-המקומי (אפס-RC), חבירה-לבלוק ~3.1s, מטח 16-ops/בלוק מ-4 חותמים.

### 1.3 מטריצת-השרשראות כפי-שהיא עכשיו

| שרשרת | מצב-אינטגרציה | איפה בקוד | מה חסר |
|---|---|---|---|
| **Steem** | ✅ מלאה — צי, DEX, אוטובוס `id=saos`, עיגון-ראשי | `agent/agent.cjs`, `src/lib/steem/saos-dex.ts` | — |
| **Hive** | ✅ מלאה — עיגוני-גשר, צי דו-שרשרתי, RC-דיסציפלינה | `dhive` + `anchor.cjs` + fleet-router | — |
| **Hive-Engine** | ✅ חיה — BEE-wall, SWAP.HIVE, AFIT, SPORTS, WAIV, ג'נזיס-SAOS-on-HE | `agent/bee_wall.cjs`, `he_*` | הרחבה ל-LEO |
| **TRON** | ✅ חיה (Tasks 90–92) — גשר-ריבוני, טבעת-6-חיילים אפס-עמלה, פעימה-24/7, נגזרות-USDT | `sovereign/node/tronbridge.cjs` | — |

| **LEO / InLeo** | ❌ **לא-קיימת** — אפס-אזכור-מהותי בקוד | — | **הבנייה מאפס — ליבת המשימה** |

### 1.4 מה-כבר-הוכח (נדרש לשימור בפלטפורמה)

- שחזור-עולם מהשרשרת הציבורית 11/11 (`rebuild.cjs`) — מנוע-עומסים 450K swaps/שנ׳.
- cloud-heart: GitHub-Actions משתלט תוך 3 דק׳ אם המארח מת (Drill-D/E — stranger-revive ב-90 שנ׳).
- כספת-צי AES-256-GCM + נגזרת-מפתחות-דטרמיניסטית + עיגון-חילוץ (אפס-אובדן-מפתחות).
- עיגוני-Hive מאומתים-עד-הסוף (verify_pendings), אפס-דימום-עסקאות (live-dedup, חלון-חי 100%).
- גשר-TRON עם קידוד-checkpointHash בשבר-ה-TRX — שזיר SAOS→TRON→SAOS ניתן-לאימות-עצמאי ב-TronScan.

## 2. הפלטפורמה-המרכזית — ארכיטקטורת-היעד (steem-engeiner)

### 2.1 התפקיד

`steem` = הראייה ההיסטורית (המעבדה שהוכיחה-הכל).
`steem-engeiner` = **קו-הייצור** — הפלטפורמה-המרכזית של הרשת: רובד-אחד מעל 4 שרשראות-תוכן (Steem·Hive·LEO·Blurt) + השרשרת-הריבונית SAOS-NET כשכבת-ההסכמה.

### 2.2 מפת-שכבות-היעד

```
┌─────────────────────────────────────────────────────────────────┐
│ הפלטפורמה (Next.js 16 · RTL) — פורטל-רשת + קונסולה + אקספלורר  │
└──────────▲──────────────────────────────────────────▲──────────┘
           │ /api/** (route handlers, אין server-actions)         │
┌──────────┴──────────────────────────────────────────▼──────────┐
│ שכבת-הרשת-המרכזית: הדמון (לולאות) + ראוטר-שרשראות רב-ערוצי   │
└───┬────────────┬────────────┬────────────┬────────────┬──────┘
    │ steem-js   │ dhive      │ dhive/     │ blurtjs-   │ tronweb
    │            │            │ HE(ssc)    │ sign-ידני  │
┌───▼────┐  ┌────▼───┐  ┌─────▼────┐  ┌────▼───┐  ┌────▼───┐
│ STEEM  │  │ HIVE   │  │ LEO·InLeo│  │ BLURT  │  │ TRON   │
│ עוגן-א │  │ עוגן-ב │  │ עוגן-ג+  │  │ עוגן-ד │  │ זמן-חי │
│ אוטובוס│  │ גשר-צי │  │ engine-  │  │ צמתים- │  │ עדות-  │
│ id=saos│  │ HE     │  │ LEO/LEOM │  │ משלנו  │  │ 24/7   │
└────────┘  └────────┘  └──────────┘  └────────┘  └────────┘
           כל העליון = עדי-ראיה בלבד. המצב שלנו ב-SAOS-NET (sha256+quorum)
```

### 2.3 עמודי-התווך (עקרונות שלא נזוזים מהם)

1. **השרשראות המארחות = שכבת-חתימה+עיגון+כלכלה-חיצונית** — המצב שלנו תמיד ב-SAOS-NET עם kernel-replay.
2. **אוטובוס-אחד חתום** — `custom_json id="saos"` (protocol `saos/v1` / `saos:net/v1`) בכל שרשרת-תוכן; LEO מצטרף כעוגן-ג עם אותו פרוטוקול בדיוק.
3. **מפתחות מחוץ-ל-git לעולם** — כספת + נגזרת-דטרמיניסטית + חתימה-מקומית, WIF לא בלוגים (sanitize).
4. **כנות-מדודה** — כל שרשרת עם health-gate (כמו blurt-cooldown): dead=מדלגים-בכנות, לא מבזבזים-מחזורים.
5. **exec-whitelist + proof-gate** — ה-API לא מריץ מה שלא נרשם; כל באדג' מגיע מקובץ-תוצאה שאומת get_transaction עצמאי.
6. **RTL עברי תמיד** — המפעיל לא קורא אנגלית-קוד; דוח-חי `docs/REPORT_HE.md` נמשך.

## 3. תוכנית-העבודה (פאזות — מה נבנה בהודעות הבאות)

### פאזה-0 · בסיס (בוצע)
- [x] שכפול מלא כולל-היסטוריה → `steem-engeiner` (פרטי, commit 4cf6eac).
- [x] תמצית-מהנדס זו.

### פאזה-1 · מפת-LEO (החלק-החסר-היחיד)
1. **סקר-מדוד**: InLeo מריץ LEO על Hive-Engine + ממשק-threads על Hive; נמדוד חי: `ssc` tokens-contract (LEO, LEOM), עוגני-פרסום (beneficiaries/permlinks), ו-`leofinance`-tags — כמו שנמדדו AFIT/BEE במקור.
2. **עוגן-ג**: עיגון-צ'קפוינטים דרך ראוטר-הצי גם-על פוסטים/threads-LEO (ערוץ-ראיה שלישי).
3. **רוטר-כלכלה**: מדרגת-ערך מורחבת — SWAP.HIVE→LEO→SWAP.LEO/HIVE-liquidity (דוגמת genesis-הקיים BEE-0.353@0.5665, נמדד-חי לפני-חיבור).

### פאזה-2 · החייאת-Blurt
1. סריקת-צמתים ציבוריים (probe מקביל + דירוג-latency) / הקמת-צומת-משלנו (ולידטור קל).
2. חיבור `blurtBroadcast` (הקוד-הקיים, חתימה-ידנית שכבר-עוקפת renumber-ops) לעוגן-ד.
3. health-gate-כנות נשאר — Blurt חוזר כעוגן-רביעי בלי לשבור שום פעימה.

### פאזה-3 · הפלטפורמה-כמוצר
1. **פורטל-הרשת**: מעבר-לקונסולה — עמוד-ראשי ציבורי (אקספלורר-רשת חי, עוגני-4-שרשראות, מטריצת-הוכחות), מאחוריו הקונסולה המלאה.
2. **ריבוי-ראשים** (v1-הסכמה): round-robin ראשים במקום ראש-יחיד — הצי כבר חותם, עכשיו גם בונה-בלוקים ברוטציה.
3. **API-ציבורי**: `/api/net/**` — כל-אדם מאמת-עצמאית את הרשת (verify-pack מורחב ל-4 שרשראות).

### פאזה-4 · כלכלת-הרשת
- ג'נזיס-SAOS-on-HE כבר ממתין ל-100-BEE — נקשר אליו נזילות-LEO/Blurt ונמדוד-ריבוי-רוטרים.
- paymaster/payroll/fuel-lines מורחבים לחיילים-החדשים על כל-עוגן.

## 4. כללי-עבודה (מהמקור — נשמעים-מילה-במילה)

- Node CJS לדמון (לא bun — secp256k1), `bun run dev` לקונסולה, `bun run db:push` לפריזמה.
- כל-מדידה→קובץ-תוצאה JSON→עיגון-בלוק→דוח-עברי. אין סימולציות.
- כל-שינוי-מפרט = fork-מתועד ב-worklog.
- כנות-אדומה קדושה: אם-שרשרת-מתה — כותבים-שהיא מתה, מקררים, וממשיכים בשאר.
