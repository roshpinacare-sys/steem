# Open Research Questions

These questions prevent the roadmap from treating hypotheses as facts.

## Intelligence and reasoning

- Which Titai workloads benefit from additional reasoning depth, and where does it
  create delay or error amplification?
- Can a controller predict when to decompose, search, call tools, critique, ask for
  approval, or stop using only observable state?
- How much improvement comes from better context selection versus a larger model?
- How should uncertainty be calibrated and surfaced without exposing private chain
  of thought or creating false precision?

## Memory and knowledge

- Which facts deserve durable memory, who owns them, and how are correction and
  forgetting proven across derived indexes?
- What retrieval method wins on Titai's actual data after deletion, freshness,
  permission, and provenance are included in the benchmark?
- How should conflicting memories and sources be represented without silent overwrite?

## Agents, tools, and protocols

- What is the smallest internal task contract that can support local execution,
  multiple agents, MCP, and A2A without inheriting protocol-specific assumptions?
- Which tool isolation boundary is justified for each risk tier and deployment profile?
- How can remote tool descriptions and retrieved documents remain untrusted data while
  still being useful to the model?

## Sovereignty, cost, and infrastructure

- What core workflows must remain available during complete network loss?
- Which local hardware profiles deliver acceptable quality, latency, thermals, and
  energy for the selected beachhead workflows?
- At what measured load does a worker process, server database, queue, or remote burst
  become simpler overall than the local embedded profile?

## Product advantage

- Which users value local control, recoverability, evidence, and domain workflow depth
  enough to switch from general-purpose assistants?
- Which capabilities create compounding data, workflow, trust, or integration advantage
  without trapping the user?
- What should Titai deliberately refuse to build because it increases surface area
  without improving a selected workflow?
