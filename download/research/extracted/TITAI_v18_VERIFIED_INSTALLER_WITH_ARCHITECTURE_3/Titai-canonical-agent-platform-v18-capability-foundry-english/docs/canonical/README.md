# Titai Canonical Research and Execution Pack

This directory is a complete English-only operating pack for converting broad AI
research into controlled engineering work. It covers product strategy, reasoning,
context, models, durable execution, agents, protocols, tools, identity, data,
memory, knowledge, security, supply chain, observability, evaluation, operations,
sovereignty, economics, energy, developer platform, human oversight, legal concerns,
and continuous research.

## Commands

- `npm run canonical:validate` — validate documents, claims, sources, ADRs, tasks,
  dependencies, coverage, and English-only content.
- `npm run canonical:next` — list dependency-ready tasks in priority order.
- `npm run canonical:context -- TASK-ID` — generate a bounded agent context pack.
- `npm run language:validate` — fail on Hebrew Unicode content in repository text files.

## The six-state distinction

Agents must not blur an observed fact, an external claim, a hypothesis, a decision,
a specification, and an implementation task. Only an accepted decision and a
bounded task can authorize architectural implementation.

## Raw research availability

Earlier interactive deep-research outputs were not included as files in the supplied
repository. This pack contains the actionable synthesis, primary-source registry,
claims ledger, open questions, experiment catalog, technology candidates, decisions,
tasks, and traceability. Exported raw reports may be added under a future
`research/raw/` directory but remain non-authoritative background.
