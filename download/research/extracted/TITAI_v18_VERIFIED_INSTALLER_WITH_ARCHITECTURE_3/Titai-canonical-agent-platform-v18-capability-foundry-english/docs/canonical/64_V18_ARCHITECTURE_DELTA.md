# TITAI v18 Architecture Delta

v18 adds a bounded Capability Operating System above the durable v17 substrate: signed packages, scoped registry, Foundry, typed Mission Compiler, gap detection, policy compiler, restricted low-risk sandbox, controlled self-improvement, role-separated teams, reusable evaluations, evidence-linked knowledge, persistent state, APIs, and an operator surface.

Authority remains outside prompts, memories, models, and packages. Physical sovereign-pilot blockers from v17 remain unchanged.
