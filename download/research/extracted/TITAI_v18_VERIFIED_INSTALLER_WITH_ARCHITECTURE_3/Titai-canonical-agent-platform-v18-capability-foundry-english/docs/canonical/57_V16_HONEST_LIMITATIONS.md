# TITAI v16 Honest Limitations

## Independently or reproducibly verified in this environment
- Canonical, language, lint, migration, type, release, and Roast source gates.
- Sixty-four isolated test files and 195 tests with bounded process exit.
- Full production build with bounded workers.
- Portable purpose-separated encrypted key custody.
- Governed lexical retrieval without embeddings or network.
- Real v15-to-v16 SQLite migration application and rollback.
- Clean source dependency installation from a preverified npm cache with registry access disabled.
- Linux process-attributed network evidence for the sovereign proof workflow.
- Separate-process signed worker execution with tenant/workspace scope and replay rejection.

## Implemented and tested but not a full production proof
- Local runtime lifecycle and loopback adapters.
- Signed isolated-node execution on one physical host.
- Network evidence based on Linux `/proc` sampling plus application instrumentation.
- Offline installation that assumes a compatible preinstalled Node runtime and a cache prepared before disconnection.

## Environment blocked
- Real browser E2E and accessibility: managed Chromium returns `ERR_BLOCKED_BY_ADMINISTRATOR` for localhost.
- Real local generative model benchmark: no hash-verified model artifact and no local model endpoint were available; shell acquisition was unavailable.
- OS or hardware-backed key custody: no target keychain, TPM, smart card, or hardware token was available.
- Target mini-PC energy measurement: the current container exposes no supported energy counter and is not the target machine.

## Not claimed
- A bare-metal offline installer containing Node and all platform packages.
- Quality or safety of Qwen, llama.cpp, Ollama, or any other local model runtime.
- Two-physical-machine synchronization or automatic conflict merging.
- Windows process-level socket attribution.
- Hardware-backed non-exportable signing keys.
- Controlled pilot readiness.

## Release decision
SOVEREIGN DEVELOPMENT MODE plus DEVELOPMENT ONLY. Unknown model, browser, hardware-key, target-energy, and final independent environment evidence remain blocking.
