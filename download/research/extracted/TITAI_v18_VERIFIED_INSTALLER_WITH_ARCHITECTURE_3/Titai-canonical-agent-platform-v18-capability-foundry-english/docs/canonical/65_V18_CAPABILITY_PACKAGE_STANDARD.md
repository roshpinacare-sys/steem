# TITAI v18 Capability Package Standard

The canonical schema is `titai.capability.v1`. Every package binds publisher, provenance, commit, files, hashes, license, compatibility, entrypoint, runtime, sandbox, dependencies, permissions, data classifications, tenancy, resource limits, side effects, approvals, idempotency, tests, evaluations, evidence, migrations, rollback, uninstall, expiry, and Ed25519 signature.

Registry states are available, quarantined, under review, qualified, installed, active, degraded, revoked, deprecated, rollback required, and incompatible.
