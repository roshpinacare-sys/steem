# docs/history — the archived audit trail

Everything here is **provenance, not current documentation**.

- `BASELINE-VERIFICATION.md` — the first real execution of this codebase
  (2026-07) and what it found. Read this first.
- `audits/` — the archive's iterative "audit pass" logs (passes 10–73).
  Genuinely interesting engineering narrative, but produced in a sandbox
  that could never run the code; treat every "PASS"/"verified" claim as
  a static-analysis claim at best.
- `07-MANIFEST.md`, `08-VALIDATION.md`, `09-GAP-ANALYSIS.md` — point-in-time
  snapshots containing known-false statements (e.g. a 47,970-file count for
  a 343-file tree, PASS marks for files that do not exist).
- `CHANGELOG-legacy.md` (274 KB) and `ENGINEERING-NOTES.md` — the generated
  running logs; the curated changelog now lives at the repo root.
- `CONSOLIDATION-NOTES.md` — how the three original archives were merged.
