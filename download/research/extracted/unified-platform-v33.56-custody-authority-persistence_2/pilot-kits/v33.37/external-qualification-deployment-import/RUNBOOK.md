# External qualification execution runbook

1. Assign eleven independently administered roles before generating keys.
2. Provision a public DNS name and TLS 1.3 certificate for the publisher.
3. Record provider evidence for every publisher, monitor and time-source host.
4. Have both topology auditors independently attest the host, organization and administrator separation.
5. Have every role sign the deployment-manifest digest.
6. Run the V33.36 HTTPS qualification protocol on the external topology.
7. Request a fresh import challenge from the evidence importer.
8. Export an exact inventory-bound evidence bundle.
9. Restore one durable monitor receipt from backup and obtain the recovery-verifier attestation.
10. Import and verify the exact bytes. Keep production promotion and G3 blocked pending all other gates.

Never reuse a challenge, share administrators across roles, lower quorum, or relabel local evidence as external.
