# External execution checklist

- [ ] Three adapter/provider classes are independently administered.
- [ ] Module bytes, ABI, interface and conformance vectors are retained.
- [ ] Attestation roots are pinned outside platform control.
- [ ] Five role keys have unique device and challenge evidence.
- [ ] Three separated custodians approve the same operation.
- [ ] Checkpoint uses public DNS and real public-network retrieval.
- [ ] Three separated monitors retain exact fsync receipts.
- [ ] Recovery site and provider differ from the source.
- [ ] Exact restored bytes match the checkpoint.
- [ ] No key material is exported.
- [ ] External human participant count remains explicit.
- [ ] Production promotion remains blocked.
