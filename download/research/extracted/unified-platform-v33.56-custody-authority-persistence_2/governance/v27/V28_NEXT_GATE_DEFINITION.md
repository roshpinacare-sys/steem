# v28 Next Gate — External Qualification and Human Value

V28 is permitted to run only bounded external qualification:
1. PostgreSQL 16 primary/standby, pool isolation, failover and PITR.
2. Authorized KMS/HSM signing, rotation, revocation and custody review.
3. Independent isolation escape, resource and penetration assessment.
4. Licensing review.
5. Consented five-participant comparison of assisted vs non-assisted review.
6. Multi-host SLO, capacity and DR rehearsal.

Stop on tenant leakage, self-approval, untrusted effect, evidence tampering, duplicate effect or unsupported human/production claim.
