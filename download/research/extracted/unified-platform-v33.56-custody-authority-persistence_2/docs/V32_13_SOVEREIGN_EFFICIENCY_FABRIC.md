# v32.13 Sovereign Efficiency Fabric

## Result

v32.13 consolidates paid routing, semantic cache, duplicate-job suppression, overload protection, cost accounting, topology selection and capacity planning into repository-owned primitives. It does not claim ownership of carrier, banking or global anycast networks.

## Native execution path

Every work request is bound to tenant, workload, operation, sensitivity, source, policy, authority and freshness. Routing prefers exact cache, bounded semantic cache, deterministic rules, local models and asynchronous local work. Qualified burst or an external model is used only when the policy, sensitivity, latency and cost envelope permits it.

Concurrent equivalent work is executed once. Admission is acquired inside the single-flight operation, so joiners do not consume duplicate capacity. Restricted material cannot enter semantic reuse. Cost events form an append-only digest chain.

## Capacity and infrastructure

The exact topology optimizer minimizes normalized operator-supplied cost while preserving two compute/database nodes, reserved CPU and memory, independent witness, independent backup, provider diversity and failure-domain diversity. The capacity controller emits proposal-only scale-to-zero and burst plans; it cannot mutate a host or cloud account.

## Honest boundaries

Public email deliverability, SMS carrier delivery, regulated payment rails and global anycast remain adapters to external networks. PostgreSQL HA/PITR/RLS, HSM/KMS, independent witness/verifier and multi-host load/failover remain production qualification gates.

## Evidence classification

The repository workload is synthetic and proves algorithmic behavior, deterministic accounting and control enforcement only. Provider costs are normalized input examples, not current quotations. Production promotion remains blocked.
