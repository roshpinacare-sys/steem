# V33.28 External Operator Ceremony and Witness Network

V33.28 adds a signed key-enrollment ceremony, dual-custodian approval, key rotation and emergency revocation, a persistent witness-network ledger, freshness controls, and unanimous all-active-witness policy. It preserves the 14-item signed program parameter ledger. It does not use majority voting and does not create production authority.

## Truth boundary

Local generated identities and synthetic observations exercise the contracts only. External qualification requires independently operated hosts, organizations, keys and live scanner/witness evidence. Any missing witness, stale evidence, split view, role overlap or infrastructure uncertainty fails closed.
