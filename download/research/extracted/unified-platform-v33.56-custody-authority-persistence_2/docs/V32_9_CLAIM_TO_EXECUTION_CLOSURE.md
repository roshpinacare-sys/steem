# v32.9 Claim-to-Execution Closure

CLAIM-V32.9-FULL: The repository-local full suite is accepted only when the authoritative test report is passed and lifecycle-clean.

CLAIM-V32.9-COVERAGE: Coverage thresholds remain machine-enforced at or above the configured line, branch, and function floors.

CLAIM-V32.9-ARCHITECTURE: Architecture closure requires every declared capability path to be closed with no source cycles and no untested source modules.

CLAIM-V32.9-MUTATION: Mutation claims are accepted only with a green baseline, authentic marker-specific kills, zero survivors, and zero invalid kills.

CLAIM-V32.9-ADAPTERS: External assurance adapters are bounded file-import capabilities without network access or runtime authority.

External production, human-value, signed-provenance and qualification claims remain blocked until observed independent evidence exists.
