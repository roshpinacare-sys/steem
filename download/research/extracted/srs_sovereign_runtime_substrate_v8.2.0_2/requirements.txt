# Reproducible installs:

#
# For hash-verified, fully reproducible installs, first generate a hash-pinned
# lock file with `pip-compile --generate-hashes` (or `pip hash`), then install
# with:
#
#   pip install --require-hashes -r requirements.txt

# (Hash-pinning requires every transitive dependency to also be listed with its
#  sha256 hash. Run `pip freeze | pip hash` or `pip-compile --generate-hashes`

# All versions are pinned to == to avoid CVE-vulnerable lower bounds. The
# previously-declared lower bounds (>=) allowed:
#   - torch>=2.0  → admitted torch 2.0.x with CVE-2024-7565 (DoS in
#     torch.load) and CVE-2024-48026 (arbitrary code execution via crafted
#     .pt archive). Pinning torch==2.2.2 avoids both.
#   - Pillow>=10.0 → admitted Pillow 10.0.x / 10.1.x with CVE-2023-50447
#     (arbitrary code execution in ICNS parser) and CVE-2024-28219 (buffer
#     overflow). Pinning Pillow==10.3.0 avoids both.
#   - numpy, z3-solver, pypdf, matplotlib had no high-severity CVEs in their
#     permitted ranges but are pinned for reproducibility.
# =============================================================================
