## 0. Context and Mission Restatement

The v6.42 closure theorem claimed that under assumptions A1–A5, every practical computational advantage reduces to one of five primitives {C, A, S, V, E}. v6.43 falsified this with the P/poly advice counterexample (L = {1^n : n-th TM halts}, undecidable but ∈ P/poly with 1-bit advice). v6.44 attempted rescue by extending to 7 primitives {C, A, S, V, E, Adv, Q}. v6.45 (simulated PC review) gave a final verdict of "C — publishable synthesis, no new theorem," noting that the 7-primitive closure is HYPOTHESIZED rather than proven, and that the authors' own primitive definition is definition-dependent.

The v6.45 PC also said: *"If the authors wish to publish in a theory venue, they must … restrict the claim and prove a formal closure."* The mission of this document is to take that instruction literally: identify the strongest restricted form of the closure theorem that is provable without resolving open conjectures, and prove it (or prove that none exists).

The natural restrictions, inherited from the v6.44 formalization (Agent F1, Candidate A: complexity-class definition), are:

| Restriction | Excludes | Status |
|-------------|----------|--------|
| Uniform computation | Non-uniform advice (P/poly) | Definitional (uniform complexity classes are uniform by definition) |
| Deterministic computation | Randomness (BPP), quantum (BQP) | Definitional |

| Boolean computation | Algebraic (VP, VNP), real-valued, analog | Definitional |
| No prover | Interactive proofs (IP = PSPACE), CS proofs, SNARKs | Definitional |

Under these six restrictions, the computation model is the standard *deterministic uniform worst-case single-machine Boolean Turing machine*, possibly with a resource bound B. The 5 primitives {C, A, S, V, E} are formalized (per F1, Candidate A) as the complexity classes {L, NC, P, NP, Θ₂^P = P^NP[log]}:

| Primitive | Conceptual name | Formal class | Canonical resource |
|-----------|-----------------|--------------|---------------------|
| `E` | Execution | `P` | time ≤ n^k |
| `C` | Compression | `L = DSPACE(log n)` | space ≤ O(log n) |
| `S` | Scheduling | `NC` | depth ≤ (log n)^k, size ≤ n^k |
| `A` | Adaptivity | `P^{NP}[log] = Θ_2^P` | adaptive queries ≤ O(log n) |
| `V` | Verification | `NP = PCP[O(log n), O(1)]` | verifier queries ≤ O(1) |

The restricted closure conjecture is the statement that these 5 classes "cover every practical advantage" available to the restricted computation model. The mission is to formalize and prove (or refute) this.

## Task 1 — Formalization of the Restricted Closure Conjecture

### 1.1 The Restricted Computation Model

Let M_B denote the **restricted computation model**: the set of all languages L ⊆ {0,1}* decidable by a deterministic uniform worst-case single-machine Boolean Turing machine within resource bound B. The bound B is a function of input length n; standard choices include:

- B(n) = n^{O(1)} → M_B = P (deterministic polynomial time)
- B(n) = O(log n) space → M_B = L (deterministic logspace)
- B(n) = (log n)^{O(1)} depth, n^{O(1)} size → M_B = NC
- B(n) = n^{O(1)} space → M_B = PSPACE
- B(n) = 2^{n^{O(1)}} time → M_B = EXPTIME
- B(n) = 2^{2^{n^{O(1)}}} time → M_B = 2-EXPTIME
- B(n) = unrestricted (decidable) → M_B = R

For the closure analysis we treat B as a free parameter and ask, for each B, whether the 5-primitive set covers M_B.

### 1.2 The Primitive Set

Following Agent F1's Candidate A (complexity-class definition; v6.44_FORMAL_PRIMITIVE_DEFINITION.md §1.A.2), the 5 primitives are the complexity classes:

  Π_5 := { L, NC, P, NP, Θ_2^P }.

The "closure" of the primitive set is the union:

  ⋃ Π_5 := L ∪ NC ∪ P ∪ NP ∪ Θ_2^P.

### 1.3 A First Observation: The Union Collapses

**Lemma 1.3 (Union collapse).** [PROVEN] ⋃ Π_5 = Θ_2^P.

*Proof.* We show all 5 classes are contained in Θ_2^P; since Θ_2^P is itself in the union, equality follows.

- **L ⊆ P.** A logspace TM has at most polynomially many configurations on inputs of length n, hence halts in polynomial time. [PROVEN; Arora-Barak Thm 4.2]
- **NC ⊆ P.** A polynomial-size polylog-depth circuit can be evaluated by a TM in polynomial time (level-by-level evaluation). [PROVEN; Borodin 1977]
- **P ⊆ NP.** A deterministic polytime computation is a special case of a nondeterministic one (the verifier ignores the certificate). [PROVEN; Cook 1971]
- **NP ⊆ Θ_2^P = P^NP[log].** Any NP language is decidable by a polytime machine making 1 query to an NP oracle, and 1 ≤ O(log n). [PROVEN; Hemachandra 1989, Wagner 1990]
- **Θ_2^P ⊆ Θ_2^P.** Trivial.

By transitivity, L, NC, P, NP ⊆ Θ_2^P. Hence ⋃ Π_5 ⊆ Θ_2^P. The reverse inclusion is trivial. ∎

**Corollary 1.3.1.** [PROVEN] The "5 primitives" are, formally, a single class Θ_2^P. The set {L, NC, P, NP, Θ_2^P} is a chain of subclasses of Θ_2^P, not an antichain. (This restates v6.44 Agent F1's central finding that the 5 primitives form a partial order, not a 5-element antichain as v6.42 claimed.)

**Significance.** This collapse is the first major simplification. The "5-primitive closure" is not a statement about 5 distinct classes — it is the single statement that Θ_2^P covers M_B. The "5" in v6.42's "5 primitives" is a definition-dependent count; under the formal complexity-class reading, the 5 collapse to 1.

### 1.4 Formal Statement of the Restricted Closure Conjecture

With Lemma 1.3 in hand, the restricted closure conjecture takes a single-parameter form:

**Conjecture 1.4 (Restricted Closure Conjecture, RCC[B]).** For a resource bound B, the restricted closure holds iff

  M_B ⊆ Θ_2^P.                                                  (RCC[B])

Equivalently: every language decidable by a deterministic uniform worst-case single-machine Boolean TM within bound B is in Θ_2^P = P^NP[log].

**Remark 1.4.1.** Note that Θ_2^P is *not* a deterministic class — it requires an NP oracle. This already introduces a subtlety: the restricted computation model M_B is deterministic, but the primitive set includes nondeterministic classes (NP, Θ_2^P). The closure claim is therefore not "M_B equals the 5-primitive union" but "M_B is contained in the 5-primitive union." The 5 primitives may be strictly more powerful than the restricted model (e.g., for B = P, NP contains problems believed outside P). This is fine for a *containment* claim; it would not be fine for an *equality* claim.

**Remark 1.4.2.** The choice of B is critical. There is no canonical "natural" resource bound for "practical" deterministic computation. Common choices in the literature:

- P (polynomial time) — the standard "tractable" class.
- PSPACE (polynomial space) — captures problems like TQBF, generalized games.
- EXPTIME (exponential time) — captures chess-like games.
- 2-EXPTIME — decision procedures for some formal systems (e.g., Presburger arithmetic with multiplication, certain modal logics).

We will analyze RCC[B] for each of these choices in §2.

## Task 2 — Attempted Proof of RCC[B], Parameterized by B

We attempt to prove RCC[B] for each candidate bound B. For each B, we either prove the closure (if B is small), or identify the open conjecture required (if B is intermediate), or prove the closure fails (if B is large).

### 2.1 B = L (deterministic logspace)

**Claim.** M_L ⊆ Θ_2^P. [PROVEN, TRIVIAL]

*Proof.* M_L = L. By Lemma 1.3, L ⊆ Θ_2^P. ∎

This is trivially true and trivially uninteresting. The restricted model equals the smallest primitive.

### 2.2 B = NC

**Claim.** M_NC ⊆ Θ_2^P. [PROVEN, TRIVIAL]

*Proof.* M_NC = NC. By Lemma 1.3, NC ⊆ Θ_2^P. ∎

Trivial.

### 2.3 B = P (deterministic polynomial time)

**Claim.** M_P ⊆ Θ_2^P. [PROVEN, TRIVIAL]

*Proof.* M_P = P. By Lemma 1.3, P ⊆ Θ_2^P. ∎

Trivial. The closure holds for B = P, but only because P is one of the 5 primitives. There is no "closure" in any non-trivial sense — the restricted model is a subclass of one of the primitives by definition.

### 2.4 B = NP (nondeterministic polynomial time)

Here we already leave the deterministic realm, but NP is a natural boundary because it is the second-smallest of the 5 primitives. We include this case for completeness.

**Claim.** M_NP ⊆ Θ_2^P. [PROVEN, TRIVIAL]

*Proof.* M_NP = NP. By Lemma 1.3, NP ⊆ Θ_2^P. ∎

Still trivial.

### 2.5 B = Θ_2^P

**Claim.** M_{Θ_2^P} ⊆ Θ_2^P. [PROVEN, TRIVIAL]

Tautological.

### 2.6 B = PH (polynomial hierarchy)

The polynomial hierarchy PH = ⋃_k Σ_k^P is the natural next class above Θ_2^P. Σ_2^P = NP^NP contains Θ_2^P; Σ_3^P, Σ_4^P, … are higher.

**Claim.** M_PH ⊆ Θ_2^P, i.e., PH ⊆ Θ_2^P. [UNKNOWN — OPEN]

*Proof attempt.* We would need to show that every level Σ_k^P (k ≥ 3) collapses to Θ_2^P. The first non-trivial level is Σ_3^P = NP^NP^NP. By definition, Σ_3^P ⊇ Σ_2^P ⊇ Θ_2^P. The reverse inclusion Θ_2^P ⊇ Σ_3^P would imply PH collapses to level 2 (since PH = ⋃_k Σ_k^P, and Σ_k^P ⊆ Σ_{k+1}^P, collapse at any level cascades to all higher levels).

But: **the polynomial hierarchy is widely believed NOT to collapse.** In particular:

- If PH collapses to level 2 (Σ_2^P = Π_2^P = PH), then PH ⊆ Δ_3^P, but this does not directly give PH ⊆ Θ_2^P.
- The standard conjecture is that PH is infinite (does not collapse at any finite level). [Widely believed; see Arora-Barak §5]

Therefore, **PH ⊆ Θ_2^P requires the open conjecture that PH collapses to Θ_2^P, which is widely believed FALSE.**

*Where the proof breaks.* At the first non-trivial level: Σ_3^P ⊆ Θ_2^P would require showing that 3 quantifier alternations reduce to 2 adaptive NP queries. There is no known reduction; the standard belief is that 3 alternations are strictly more powerful than 2 (i.e., Σ_3^P ⊋ Σ_2^P, which is the "PH does not collapse to level 2" conjecture, widely believed but OPEN).

*Verdict for B = PH.* [UNKNOWN, conditional on PH collapse to level 2 — widely believed FALSE]

### 2.7 B = PSPACE (deterministic polynomial space)

By Savitch's theorem (Savitch 1970), NPSPACE = PSPACE, so PSPACE captures both deterministic and nondeterministic polynomial-space computation. PSPACE contains PH (trivially: each level of PH is in PSPACE). PSPACE contains TQBF, the canonical PSPACE-complete problem (Stockmeyer-Meyer 1973).

**Claim.** M_PSPACE ⊆ Θ_2^P, i.e., PSPACE ⊆ Θ_2^P. [UNKNOWN — OPEN]

*Proof attempt.* We have Θ_2^P ⊆ PH ⊆ PSPACE. The reverse inclusion PSPACE ⊆ Θ_2^P would require PSPACE = Θ_2^P, which by the chain Θ_2^P ⊆ PH ⊆ PSPACE implies both PH = PSPACE and PH = Θ_2^P (i.e., PH collapses to level 2).

So PSPACE ⊆ Θ_2^P requires TWO widely-believed-false conjectures:
1. PH collapses to Θ_2^P (widely believed false).
2. PH = PSPACE (widely believed false; TQBF is the canonical "PH does not reach" candidate).

*Where the proof breaks.* At PSPACE ⊆ PH: we would need to show that TQBF (a PSPACE-complete problem) is in PH. There is no known reduction; the standard belief is that TQBF ∉ PH (equivalently, PH ⊊ PSPACE), which is OPEN.

*Verdict for B = PSPACE.* [UNKNOWN, conditional on PH = PSPACE AND PH = Θ_2^P — both widely believed FALSE]

### 2.8 B = EXPTIME (deterministic exponential time)

EXPTIME = ⋃_k DTIME(2^{n^k}). It contains PSPACE (since a PSPACE computation has at most 2^{poly(n)} configurations, hence can be simulated in 2^{poly(n)} time). It contains EXPTIME-complete problems such as generalized chess (Fraenkel-Lichtenstein 1981).

**Claim.** M_EXPTIME ⊆ Θ_2^P, i.e., EXPTIME ⊆ Θ_2^P. [UNKNOWN — OPEN, but PROVABLY ⊊ 2-EXPTIME]

*Proof attempt.* We have Θ_2^P ⊆ PH ⊆ PSPACE ⊆ EXPTIME. The reverse inclusion EXPTIME ⊆ Θ_2^P would require EXPTIME = Θ_2^P, which by the chain implies PH = PSPACE = EXPTIME (collapsing 3 widely-separated classes).

The status of PSPACE vs EXPTIME is OPEN. By the deterministic time hierarchy theorem (Hartmanis-Stearns 1965), we know:

  DTIME(2^n) ⊊ DTIME(2^{n^2}) ⊊ DTIME(2^{n^3}) ⊊ … ⊆ EXPTIME.

So EXPTIME has a strict internal hierarchy. But this doesn't directly separate EXPTIME from PSPACE.

What we CAN prove:

  P ⊊ EXPTIME.                                                        [PROVEN, Hartmanis-Stearns 1965]

But this only separates P (the smallest primitive) from EXPTIME — it doesn't separate Θ_2^P (the largest primitive) from EXPTIME.

*Where the proof breaks.* We need either (a) PH = PSPACE = EXPTIME (very implausible), or (b) a direct separation EXPTIME ⊋ Θ_2^P. Neither is known.

*Verdict for B = EXPTIME.* [UNKNOWN, conditional on multiple implausible collapses]

### 2.9 B = 2-EXPTIME (deterministic double-exponential time)

2-EXPTIME = ⋃_k DTIME(2^{2^{n^k}}). It contains 2-EXPTIME-complete problems such as the decision problem for Presburger arithmetic with multiplication (or certain modal logics; see Börger-Grädel-Gurevich 1997).

**Claim.** M_2-EXPTIME ⊆ Θ_2^P, i.e., 2-EXPTIME ⊆ Θ_2^P. [FALSIFIED]

*Proof.* We use the **deterministic time hierarchy theorem** (Hartmanis-Stearns 1965; see also Arora-Barak Theorem 3.1), which states:

  If f, g are time-constructible with f(n) log f(n) = o(g(n)), then DTIME(f(n)) ⊊ DTIME(g(n)).

A standard corollary (proven by direct diagonalization; see Hartmanis-Stearns 1965 or Arora-Barak §3.1) is:

  **EXPTIME ⊊ 2-EXPTIME.**                                                 [PROVEN]

For completeness, we sketch the diagonalization. Enumerate all Turing machines as M_1, M_2, M_3, … (no time bound). Define a language L by:

  L(1^i) := 1 − M_i(1^i)   (with M_i simulated on input 1^i for 2^{2^i} steps; if M_i does not halt within this bound, L(1^i) := 0).

Each simulation runs in time 2^{2^i} · poly(i) = 2^{O(2^i)}, so L is decidable in time 2^{O(2^n)} ⊆ 2-EXPTIME (specifically, L ∈ DTIME(2^{2^{n+O(1)}}) ⊆ ⋃_k DTIME(2^{2^{n^k}}) = 2-EXPTIME).

Now let M be any EXPTIME machine, running in time 2^{n^k} for some k. Then M = M_i for some i. For inputs 1^i with i sufficiently large, 2^{i^k} < 2^{2^i}, so M halts within 2^{2^i} steps on input 1^i. Hence M_i(1^i) (simulated for 2^{2^i} steps) = M(1^i), and L(1^i) = 1 − M(1^i). Therefore L ≠ M. Since M was an arbitrary EXPTIME machine, L ∉ EXPTIME.

Combining, L ∈ 2-EXPTIME \ EXPTIME. Hence EXPTIME ⊊ 2-EXPTIME. ∎ (corollary of time hierarchy)

Now, by Lemma 1.3 and the standard inclusions (Arora-Barak §4–5):

  ⋃ Π_5 = Θ_2^P ⊆ PH ⊆ PSPACE ⊆ EXPTIME ⊊ 2-EXPTIME = M_2-EXPTIME.

Therefore:

  ⋃ Π_5 ⊊ M_2-EXPTIME.                                                [PROVEN]

Equivalently: M_2-EXPTIME ⊄ Θ_2^P. The restricted closure **fails** for B = 2-EXPTIME.

*Concrete separating example.* Let L ∈ 2-EXPTIME \ EXPTIME as constructed above. Then:

- L is decidable by a deterministic uniform worst-case single-machine Boolean TM in time 2^{2^{O(n)}} — i.e., L ∈ M_2-EXPTIME.
- L ∉ EXPTIME ⊇ PSPACE ⊇ PH ⊇ Θ_2^P = ⋃ Π_5.
- L satisfies all 6 restrictions: deterministic (yes), uniform (yes), worst-case (yes), single-machine (yes), Boolean (yes), no prover (yes).
- L is NOT in any of the 5 primitives.

Therefore the restricted closure conjecture is FALSIFIED for B = 2-EXPTIME. The 5 primitives do NOT cover every problem solvable within the restricted computation model (with bound B = 2-EXPTIME). ∎

### 2.10 B = R (all decidable languages)

**Claim.** M_R ⊆ Θ_2^P, i.e., R ⊆ Θ_2^P. [FALSIFIED]

*Proof.* R ⊋ 2-EXPTIME (trivially; 2-EXPTIME ⊆ R, and R contains problems not in any fixed time bound by the undecidability of the halting problem applied to time bounds). Hence R ⊋ ⋃ Π_5 by §2.9. The restricted closure fails spectacularly. ∎

### 2.11 Summary of RCC[B] by B

| Bound B | M_B | RCC[B] holds? | Status |
|---------|-----|---------------|--------|
| L | L | YES | [PROVEN, TRIVIAL] |
| NC | NC | YES | [PROVEN, TRIVIAL] |
| P | P | YES | [PROVEN, TRIVIAL] |
| NP | NP | YES | [PROVEN, TRIVIAL] |
| Θ_2^P | Θ_2^P | YES (tautology) | [PROVEN, TRIVIAL] |
| PH | PH | UNKNOWN | [CONDITIONAL ON PH collapse to Θ_2^P — widely believed FALSE] |
| PSPACE | PSPACE | UNKNOWN | [CONDITIONAL ON PH = PSPACE = Θ_2^P — widely believed FALSE] |
| EXPTIME | EXPTIME | UNKNOWN | [CONDITIONAL on multiple implausible collapses] |
| 2-EXPTIME | 2-EXPTIME | **NO** | **[FALSIFIED by time hierarchy]** |
| R | R | **NO** | **[FALSIFIED, §2.10]** |

**Pattern.** For B ≤ Θ_2^P, RCC[B] is trivially TRUE because M_B is contained in one of the 5 primitives. For B > Θ_2^P up through EXPTIME, RCC[B] is OPEN and conditional on implausible collapses. For B ≥ 2-EXPTIME, RCC[B] is PROVABLY FALSE.

## Task 3 — Where the Proof Breaks

### 3.1 The Single Failure Point

The restricted closure proof breaks at a *single, identifiable point*: the step from Θ_2^P (the largest primitive) to PH (the next class up).

  Θ_2^P ⊆ PH ⊆ PSPACE ⊆ EXPTIME ⊊ 2-EXPTIME.
            ↑
            The proof breaks here: PH ⊆ Θ_2^P is OPEN.

For RCC[B] to hold for any B > Θ_2^P (in particular, for B = PH, PSPACE, EXPTIME), one must show that the chain collapses at the level of Θ_2^P. This requires the polynomial hierarchy to collapse to level 2:

  **Conjecture (PH collapses to level 2).** PH = Σ_2^P = Π_2^P = Θ_2^P.

This conjecture is **widely believed FALSE**. The standard complexity-theoretic belief is that PH is infinite — i.e., Σ_k^P ⊋ Σ_{k+1}^P for all k. See Arora-Barak (2009), Chapter 5, for the standard exposition.

### 3.2 Why the Conjecture Is Widely Believed False

There are several lines of evidence:

1. **Relativized separation.** Baker-Gill-Solovay (1975) constructed oracles relative to which PH is infinite. Specifically, for any k, there exists an oracle A such that Σ_k^P,A ⊋ Σ_{k+1}^P,A. This shows that PH collapse cannot be proven by relativizing techniques (i.e., by any proof technique that respects oracle construction).

2. **Circuit lower bounds.** Kannan (1982) showed that for every k, Σ_2^P contains a language requiring circuits of size n^k. This is consistent with PH being infinite.

3. **Karp-Lipton-style theorems.** Karp-Lipton (1980) showed that if NP ⊆ P/poly, then PH collapses to Σ_2^P. The contrapositive: if PH does not collapse to Σ_2^P, then NP ⊄ P/poly. The widespread belief that NP ⊄ P/poly (which would imply circuit lower bounds that are themselves major open problems) is consistent with PH not collapsing.

4. **Lack of any plausible collapse mechanism.** No proof technique is known that would collapse PH to level 2. The natural proofs barrier (Razborov-Rudich 1997) rules out many approaches to circuit lower bounds, which would be needed to make progress on PH structure.

### 3.3 What Would Be Needed to Prove RCC[B] for B > Θ_2^P

To prove RCC[PH], one would need to prove PH ⊆ Θ_2^P, which is *equivalent* to PH = Θ_2^P (since Θ_2^P ⊆ PH). This is the PH-collapse-to-level-2 conjecture, widely believed false.

To prove RCC[PSPACE], one would additionally need PH = PSPACE, which is even more widely believed false (TQBF being the canonical witness).

To prove RCC[EXPTIME], one would additionally need PSPACE = EXPTIME, which is also widely believed false (chess-like games being the canonical witness).

To prove RCC[2-EXPTIME] is impossible: the time hierarchy theorem directly refutes it.

### 3.4 The Open Conjecture Required

The single open conjecture that gates the entire restricted closure program is:

  **The Polynomial Hierarchy Collapse Conjecture (PHCC).** PH collapses to Θ_2^P, i.e., PH = Σ_2^P = Π_2^P = Θ_2^P.

Status: **OPEN, widely believed FALSE** (Baker-Gill-Solovay 1975 relativized separation; standard belief that PH is infinite).

Without resolving PHCC, the restricted closure cannot be proven for any B > Θ_2^P. With PHCC resolved FALSE (the expected outcome), the restricted closure is also refuted for any B ≥ PSPACE (since PH = Θ_2^P ⊊ PSPACE is also widely believed).

The restricted closure for B in the narrow range (Θ_2^P, PH] depends specifically on PHCC. For B in the range (PH, PSPACE], it depends additionally on PH vs PSPACE. For B in the range (PSPACE, EXPTIME], it depends additionally on PSPACE vs EXPTIME. For B ≥ 2-EXPTIME, it is PROVABLY FALSE unconditionally.

### 3.5 Honest Summary of Task 3

The restricted closure proof breaks at a single, identifiable step:

  **Step.** Show that PH ⊆ Θ_2^P.
  **Theorem needed.** Polynomial hierarchy collapse to level 2.
  **Status.** OPEN, widely believed FALSE (Baker-Gill-Solovay 1975 oracle separation; standard belief that PH is infinite).
  **Required for.** RCC[B] for any B > Θ_2^P (in particular, for B = PH, PSPACE, EXPTIME).
  **Not required for.** RCC[B] for B ≤ Θ_2^P (trivially TRUE) or B ≥ 2-EXPTIME (trivially FALSE).

## Task 4 — Strongest Provable Restricted Theorem

### 4.1 The Strongest Provable Positive Statement

The strongest provable *positive* restricted closure statement is:

**Theorem 4.1 (Trivial Restricted Closure for B = Θ_2^P).** [PROVEN, TRIVIAL] For B = Θ_2^P, RCC[B] holds: M_{Θ_2^P} ⊆ Θ_2^P.

*Proof.* Tautological: M_{Θ_2^P} = Θ_2^P by definition. ∎

This is trivially true and trivially uninteresting. It corresponds to choosing the resource bound to be exactly the largest primitive.

For B < Θ_2^P, the closure is also trivially true (M_B is contained in one of the smaller primitives). These are equally trivial.

There is **no non-trivial provable positive closure statement**. Any positive closure beyond the trivial case requires PH collapse, which is open.

### 4.2 The Strongest Provable Negative Statement

The strongest provable *negative* restricted closure statement is the time-hierarchy-based falsification at 2-EXPTIME:

**Theorem 4.2 (Restricted Closure Falsification at 2-EXPTIME).** [PROVEN] For B = 2-EXPTIME (and any larger bound), RCC[B] fails:

  ⋃ Π_5 ⊊ M_{2-EXPTIME}.

*Proof.* By Lemma 1.3, ⋃ Π_5 = Θ_2^P. By the standard inclusions (Arora-Barak §4–5):

  Θ_2^P ⊆ PH ⊆ PSPACE ⊆ EXPTIME.

By the deterministic time hierarchy theorem (Hartmanis-Stearns 1965; see also Arora-Barak Theorem 3.1), via direct diagonalization as sketched in §2.9:

  EXPTIME ⊊ 2-EXPTIME.                                                 [PROVEN]

(Diagonalization sketch: enumerate all TMs M_1, M_2, …; define L(1^i) = 1 − M_i(1^i) with M_i simulated for 2^{2^i} steps. Then L ∈ DTIME(2^{O(2^n)}) ⊆ 2-EXPTIME, and L ∉ EXPTIME because for any EXPTIME machine M running in time 2^{n^k}, we have M = M_i for some i, and M halts within 2^{2^i} steps on input 1^i for large i, giving L(1^i) = 1 − M(1^i), hence L ≠ M.)

Combining:

  ⋃ Π_5 = Θ_2^P ⊆ PH ⊆ PSPACE ⊆ EXPTIME ⊊ 2-EXPTIME.

Therefore:

  ⋃ Π_5 ⊊ 2-EXPTIME = M_{2-EXPTIME}.

Equivalently: M_{2-EXPTIME} ⊄ ⋃ Π_5. The restricted closure fails for B = 2-EXPTIME. ∎

### 4.3 Concrete Counterexample to RCC[2-EXPTIME]

Let L ∈ 2-EXPTIME \ EXPTIME (exists by Theorem 4.2). Then:
