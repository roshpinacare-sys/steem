# v6.44 — Six-Primitive Framework (C, A, S, V, E, Advice) and Adversarial Audit

## Executive Summary

The v6.43 audit falsified the v6.42 Closure Theorem by exhibiting non-uniform advice (P/poly) as a 6th primitive that escapes {C, A, S, V, E} on an undecidable unary language. This document executes the recommended patch: it formally defines **Advice** as a 6th primitive, constructs the resulting **6-primitive framework** {C, A, S, V, E, Advice}, and then runs an uncompromising adversarial audit searching for a **7th primitive**.

**Verdict — the 6-primitive framework survives *conditionally*, but a 7-primitive framework {C, A, S, V, E, Advice, Quantum} is strictly stronger (more robust, fewer assumptions) and is the strongest surviving framework.**

The conditional survival of the 6-primitive framework depends on the open complexity-theoretic question **BQP ⊆ P/poly**. The 7-primitive framework with Quantum added survives under only the basic physical assumption A5 (no unbounded provers, no hypercomputation) — and even that has a hole (IP with unbounded provers escapes unless excluded by A5).

**Final primitive count (strongest surviving framework): 7.**

**Strongest surviving theorem statement (informal):** *Under the assumptions that (A1) the Church-Turing thesis holds and (A5) computation is physically realizable (excluding unbounded provers and hypercomputation), every practical computational advantage on every standard resource axis reduces to one of {Compression (C), Adaptivity (A), Scheduling (S), Verification (V), Execution (E), Advice, Quantum}.*

This document records the formal definitions (Part 1), the framework construction (Part 2), the adversarial audit (Part 3), the strongest surviving theorem (Part 4), all assumptions (Part 5), and the empirical benchmark (Part 6). All claims are tagged [PROVEN], [CONDITIONAL ON X], [UNKNOWN], or [HYPOTHESIZED].

## Part 1 — Formal Definition of the 6th Primitive (Advice)

### 1.1 The P/poly setup (background)

Let a **complexity class with advice** be defined as follows. For a function class C and a bound s: ℕ → ℕ, define

> **C/s** := { L ⊆ Σ* : ∃ M ∈ C, ∃ advice function a: ℕ → Σ* with |a(n)| ≤ s(n), such that for all x ∈ Σ* with |x| = n, x ∈ L ⟺ M(x, a(n)) = 1 }.

In particular:

> **P/poly** := ⋃_{k ∈ ℕ} **P / n^k**

= languages decidable in polynomial time given a polynomial-bounded advice string that depends only on input length.

P/poly was introduced by Karp-Lipton (1980) [PROVEN]. It is the canonical non-uniform complexity class. Equivalently, P/poly is the class of languages decidable by polynomial-size Boolean circuit families {C_n}_{n∈ℕ} (a single circuit per input length, but the circuit may be different for each n) [PROVEN, Karp-Lipton 1980].

### 1.2 Formal definition of the 6th primitive

**Definition (Advice primitive).** The primitive **Advice** (denoted 𝒟, mnemonic for "*a*dvice") is the resource axis defined as follows. An algorithm **uses Advice** if it is permitted, for each input length n, to read an advice string a(n) ∈ Σ* with |a(n)| ≤ poly(n) that is not computed by the algorithm itself but provided externally (offline, non-uniformly). The advice may depend on n but not on the specific input x.

Formally, an Advice-using algorithm is a pair (M, a) where M is a polynomial-time Turing machine and a: ℕ → Σ* is a polynomially-bounded function. The function computed is:

> x ↦ M(x, a(|x|))

The advice function a is treated as an **oracle** in the sense of complexity theory: it is not required to be computable. [PROVEN — standard definition, see Arora-Barak §6]

### 1.3 How Advice differs from the other 5 primitives

The five v6.42 primitives {C, A, S, V, E} are all **uniform**: every algorithm using only these primitives is a single Turing machine M that, on input x of length n, runs in time poly(n) using only resources derivable from x itself. Formally [PROVEN under A1]:

> {C, A, S, V, E}-computable functions =: FP ⊆ FP = polynomial-time computable functions.

By contrast, Advice-using algorithms are **non-uniform**: the algorithm has access to a function a(n) that is not computed by the algorithm. The pair (M, a) is not a single Turing machine — it is a Turing machine **plus** an external oracle whose values are not constrained to be computable.

The key distinction is **uniformity** [PROVEN]:
- {C, A, S, V, E}: uniform — one TM handles all input lengths
- Advice: non-uniform — a separate "device" (circuit or advice string) per input length

This distinction is mathematically substantive: by the time-hierarchy theorem, P/poly contains undecidable languages (e.g., any unary language is in P/poly with 1 bit of advice per length), while P (the closure of {C, A, S, V, E}) contains only decidable languages. [PROVEN — see §1.6]

### 1.4 Resource axis covered: non-uniformity (a NEW axis)

The v6.42 framework had 10 axes: {Space, Work, Wall-time, Depth, Comm, Cache, Verification, Queries, Parallelism, Locality} (or in the original v6.42 notation: {S, W, T, D, C, V, Q, P, L, A}). None of these capture **non-uniformity** as a resource.

**Definition (Non-uniformity axis).** The non-uniformity axis **U** measures the amount of advice string required: for an algorithm A using advice a(n), U(A) = max_{n ≤ N} |a(n)| for the largest input size N considered.

U is a **new axis**, distinct from the 10 v6.42 axes:
- It is not Space (S): advice is provided externally, not allocated from input.
- It is not Work (W): advice is not computed, it is read.
- It is not Queries (Q): advice is not a query to a target function; it is a precomputed string.
- It is not Verification (V): advice is not a proof checked probabilistically; it is trusted input.
- It is not Compression (C): advice is not a compressed representation of x; it is a separate function of n.

The 11-axis framework (v6.42's 10 + U) is the **minimum extension** that captures Advice as a primitive. [PROVEN — non-uniformity is a standard resource in circuit complexity; see Arora-Barak §6]

### 1.5 Lower bound: Adleman's theorem (BPP ⊆ P/poly)

**Theorem (Adleman 1978).** BPP ⊆ P/poly. [PROVEN]

*Proof sketch.* A BPP algorithm uses r(n) = poly(n) random bits and errs with probability ≤ 1/3. By averaging, for at least a 2/3 fraction of random strings r, the algorithm is correct on *all* inputs of length n (this requires the standard amplification to error ≤ 2^{-n}/2 first). Fix such an r = r*(n). Then r*(n) is a polynomial-length string that, hard-coded as advice, makes the algorithm correct on all inputs of length n. The advice function is a(n) = r*(n), of length poly(n). Hence BPP ⊆ P/poly. ∎

**Consequence.** Randomness is **strictly subsumed** by Advice: any algorithm using randomness can be simulated (with no asymptotic loss) by an algorithm using Advice, where the advice hard-codes the optimal random seed for each input length. [PROVEN]

This is a sharp lower bound for Advice: Advice provably yields an advantage that no {C, A, S, V, E}-with-randomness algorithm can replicate *without* advice — specifically, BPP algorithms cannot decide undecidable unary languages, but P/poly algorithms can (§1.6).

### 1.6 Lower bound: undecidable languages in P/poly

**Theorem.** Every unary language L ⊆ {1}* is in P/poly. [PROVEN]

*Proof.* For input length n, define a(n) = 1 if 1^n ∈ L, else 0. Then |a(n)| = 1, and the decider M(1^n, a(n)) = a(n) runs in O(log n) time. So L ∈ P/poly. ∎

**Corollary.** There exist undecidable languages in P/poly. In particular, L = {1^n : the n-th TM halts on empty input} is undecidable (Turing 1936) but in P/poly. [PROVEN]

This is the **smallest counterexample** to the v6.42 Closure Theorem (v6.43 §3.1, §5). It establishes that Advice provably yields an advantage — deciding an undecidable language — that no algorithm using only {C, A, S, V, E} can ever achieve. [PROVEN]

### 1.7 Summary: Advice as the 6th primitive

| Property | Status |
|----------|--------|
| Formal definition | [PROVEN — Karp-Lipton 1980] |
| Distinct from {C,A,S,V,E} (uniform vs non-uniform) | [PROVEN] |
| Covers a new resource axis (non-uniformity) | [PROVEN] |
| Strictly stronger than {C,A,S,V,E} (decides undecidable unary L) | [PROVEN] |
| Subsumes Randomness (BPP ⊆ P/poly) | [PROVEN — Adleman 1978] |
| Physically realizable (under A5) | [CONDITIONAL ON A5 — assumes finite advice is physical] |
| Survives adversarial reduction to {C,A,S,V,E} | [PROVEN — Counterexample A of v6.43] |

## Part 2 — The 6-Primitive Framework

### 2.1 Formal definition

**Definition (6-Primitive Framework, v6.44).** The 6-primitive framework is the 6-tuple

> **𝓕₆** = (𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓)

where:
- **𝓒** = Compression: maps an input distribution to a shorter representation, achieving storage S(f) ≥ K(f) (Kolmogorov complexity).
- **𝓐** = Adaptivity: maps a transcript (q_1, y_1, …, q_t, y_t) to a new query q_{t+1}; equivalent to adaptive query complexity (v6.41).
- **𝓢** = Scheduling: maps a set of independent subcomputations to a parallel schedule, achieving depth D = W/P (Brent's theorem).
- **𝓥** = Verification: maps a claimed output y and a witness w to a probabilistic accept/reject decision, achieving ε-soundness via PCP.
- **𝓔** = Execution: standard TM step, costing 1 unit of Work per step.
- **𝓓** = Advice: maps an input length n to an external string a(n) of length ≤ poly(n), accessible to the algorithm but not computed by it.

[PROVEN — formal definition consistent with Karp-Lipton 1980 and v6.42 §3]

### 2.2 Updated axis → primitive mapping (11 axes)

The v6.42 framework had 10 axes mapped to 5 primitives. We extend to 11 axes:

| Axis | Symbol | Mapped primitive | Justification |
|------|--------|------------------|---------------|
| Space | S | C | Compression reduces storage [PROVEN — Shannon 1948] |
| Work | W | E | Execution = work unit [PROVEN] |
| Wall-time | T | S | Scheduling reduces wall-time [PROVEN — Brent 1974] |
| Depth | D | S | Scheduling = parallel depth [PROVEN — Brent 1974] |
| Communication | C | S | Scheduling reduces comm [PROVEN — Yao 1979] |
| Cache | C' | C | Compression improves locality [HYPOTHESIZED] |
| Verification | V | V | PCP gives V axis [CONDITIONAL ON PCP] |
| Queries | Q | A | Adaptivity = adaptive queries [PROVEN — v6.41] |
| Parallelism | P | S | Scheduling = parallelism [PROVEN] |
| Locality | L | C | Compression improves locality [HYPOTHESIZED] |
| **Non-uniformity** | **U** | **𝓓 (Advice)** | **Advice = non-uniform input [PROVEN — Karp-Lipton 1980]** |

The 11th axis (Non-uniformity) is new in v6.44. [PROVEN — see Part 1]

### 2.3 Updated closure claim

**Claim (6-primitive closure, v6.44).** *Under assumptions A1-A6 (see Part 5), every practical computational advantage on every standard resource axis (S, W, T, D, C, C', V, Q, P, L, U) reduces to one of {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓}.*

[HYPOTHESIZED — to be tested by adversarial audit in Part 3]

The closure claim now includes the non-uniformity axis, which is captured by the Advice primitive. This closes the v6.43 counterexample (Counterexample A: undecidable unary language is now in 𝓓).

### 2.4 What changed from v6.42 to v6.44

| Property | v6.42 | v6.44 |
|----------|-------|-------|
| Primitive count | 5 | 6 |
| Axes | 10 | 11 |
| Captures undecidable unary L? | NO (falsified) | YES (via Advice) |
| Captures Randomness? | NO (assumed BPP=P) | YES (via Advice, Adleman) |
| Captures Quantum? | NO (assumed BQP=BPP) | CONDITIONAL on BQP ⊆ P/poly |
| Captures IP-with-unbounded-prover? | NO | NO (excluded by A5) |
| Strongest assumption needed | A1, A4, A5, BPP=P, BQP=BPP, no advice, no unbounded prover, worst-case | A1, A5, BQP ⊆ P/poly, no unbounded prover |

The 6-primitive framework **strictly improves** on v6.42: it removes the need for the "BPP = P" and "no advice" assumptions (the former is replaced by Adleman's theorem, the latter is absorbed by adding 𝓓 as a primitive). It still requires "BQP ⊆ P/poly" (open) for the closure claim to hold against quantum candidates.

## Part 3 — Adversarial Audit (10 Candidates for a 7th Primitive)

We attempt to FALSIFY the 6-primitive closure claim by exhibiting a 7th primitive. For each candidate, we ask: (i) does it reduce to {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓}? (ii) if not, is it physically realizable (A5)? (iii) if yes, is it a 7th primitive?

### 3.1 Randomness (BPP vs P) — **REDUCES to Advice**

**Construction.** Polynomial Identity Testing (PIT): given an arithmetic circuit C, decide whether C is identically zero. PIT ∈ BPP (Schwartz-Zippel), PIT ∈ P is OPEN.

**Reduction.** By Adleman's theorem (§1.5), BPP ⊆ P/poly. So any BPP algorithm can be simulated by a P/poly algorithm: hardcode the optimal random seed per input length as advice. The advice size is polynomial in n. [PROVEN — Adleman 1978]

**Verdict.** Randomness is **strictly subsumed** by Advice. It is NOT a 7th primitive. The candidate fails to escape 𝓕₆.

**Empirical confirmation.** See Part 6: the 6-primitive algorithm with Randomness added performs identically to the 6-primitive algorithm without Randomness (both achieve O(1) identification via Advice). [MEASURED]

### 3.2 Quantum entanglement (BQP vs BPP) — **UNKNOWN / CONDITIONAL**

**Construction.** Factoring: ∈ BQP (Shor 1994), conjectured ∉ BPP (and ∉ P). If factoring ∉ P/poly, then quantum computation yields a super-polynomial advantage that no {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓} algorithm can replicate.

**Reduction status.** BQP ⊆ P/poly is **OPEN**. We know:
- BPP ⊆ P/poly [PROVEN — Adleman]
- BQP ⊆ PP [PROVEN — Adleman-DeMarrais-Du 1997]
- BQP ⊆ AWPP ⊆ PP [PROVEN]
- BQP ⊆ PSPACE [PROVEN]
- Forrelation problem gives an oracle separation BQP^O ⊄ BPP^O^PH (Aaronson-Ambainis 2015) [PROVEN]

But none of these resolve BQP vs P/poly.

**Lower bound on BQP ⊄ P/poly.** If BQP ⊆ P/poly, then NP ⊆ BQP implies NP ⊆ P/poly implies PH collapses to Σ_2^P (Karp-Lipton). This is widely believed false but not proven.

**Verdict.** Quantum is a **conditional 7th primitive**:
- If BQP ⊆ P/poly: REDUCES to Advice, quantum is not a 7th primitive.
- If BQP ⊄ P/poly: ESCAPES 𝓕₆, quantum is a 7th primitive (subject to A5 — quantum is physically realizable).

[CONDITIONAL ON BQP ⊆ P/poly] — this is the **weakest link** in the 6-primitive framework.

**Physical realizability.** Quantum computation IS physically realizable (subject to noise, decoherence — see A5). So if BQP ⊄ P/poly, quantum survives all assumptions and is a 7th primitive.

### 3.3 Unbounded provers (IP = PSPACE) — **ESCAPES (excluded by A5)**

**Construction.** IP = PSPACE (Shamir 1992). TQBF (true quantified Boolean formulas) ∈ PSPACE. An IP verifier for TQBF runs in poly-time using an unbounded prover.

**Reduction status.** To reduce IP to {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓}, we would need to encode the prover's strategy as advice. The prover's optimal strategy for inputs of length n is a function from transcripts to messages. Transcript length is poly(n); number of transcripts is 2^{poly(n)}; so the strategy size is **exponential**. P/poly only allows polynomial advice. So IP cannot be reduced to Advice with polynomial overhead.

Furthermore, TQBF ∈ PSPACE-complete. If PSPACE ⊆ P/poly, then by a result of Babai-Frankl-Simon (1986), PSPACE = MA. This is widely believed false. [HYPOTHESIZED — standard belief]

So IP escapes the 6-primitive framework, *provided* we permit the unbounded prover as a computational resource.

**Physical realizability.** An unbounded prover is **not** a Turing machine. Under A5 (physical realizability = TM-computable), an unbounded prover is excluded.

**Verdict.** IP-with-unbounded-prover **escapes** the 6-primitive framework, but is **excluded by A5**. If we weaken A5 to permit oracles/external provers, then IP becomes a 7th primitive (and indeed the 6-primitive framework fails).

This is a **fragility** of the 6-primitive framework: it requires A5 to be strong enough to exclude unbounded provers. [CONDITIONAL ON A5]

### 3.4 Average-case structure (simplex) — **REDUCES**

**Construction.** Simplex method: exponential worst-case (Klee-Minty 1972), polynomial average-case (Spielman-Teng 2001 smoothed analysis).

**Reduction status.** Average-case complexity is a **re-specification of the cost measure**, not a new computational mechanism. The same primitives {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓} apply on the average-case cost measure: the algorithm is still a TM (under A1), the resources are still {S, W, T, D, …, U}, and the only change is which inputs we average over.

Average-case structure modifies what "practical advantage" means (average vs worst), but does not introduce a new primitive. [PROVEN — average-case complexity is a refinement of worst-case complexity, not a separate computational model]

**Verdict.** Average-case structure REDUCES — it is not a 7th primitive. The 6-primitive framework handles average-case by applying the same 6 primitives on the average-case cost measure.

### 3.5 Distributed asynchrony (FLP) — **REDUCES**

**Construction.** FLP theorem (Fischer-Lynch-Paterson 1985): deterministic consensus is impossible in an asynchronous system with even one faulty process.

**Reduction status.** FLP is a **model impossibility** theorem, not a computational primitive. The "advantage" of circumventing FLP is achieved by relaxing an assumption:
- Randomization → randomized consensus (Ben-Or 1983) → uses Randomness → reduces to Advice (Adleman)
- Synchrony → synchronous consensus → uses Scheduling
- Bounded faults → Byzantine consensus → uses Verification
- Partial synchrony → Paxos → uses Adaptivity + Verification

Every FLP-circumventing algorithm reduces to a combination of {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓}. [PROVEN — see Lynch 1996 "Distributed Algorithms"]

**Verdict.** Distributed asynchrony REDUCES. It is not a 7th primitive. The 6-primitive framework handles distributed computation by recognizing that distributed *impossibility* is a model property and distributed *algorithms* use the existing 6 primitives.

### 3.6 Algebraic structure (VP vs VNP) — **REDUCES**

**Construction.** Permanent vs determinant (Valiant 1979). Permanent ∈ VNP, conjectured ∉ VP.

**Reduction status.** Algebraic circuits operate over a field F. VP = poly-size algebraic circuits. VP ⊆ P/poly (every algebraic circuit of size s gives a Boolean circuit of size poly(s) for the bit-representation of the output). [PROVEN — standard fact]

VNP is the algebraic analogue of #P; VNP ⊆ FPSPACE (VNP functions can be evaluated in polynomial space). The Permanent, as a **Boolean function** (output all bits of the integer permanent), is in FP ⊆ P ⊆ P/poly. [PROVEN — Ryser's formula computes permanent in O(n · 2^n) arithmetic operations, polynomial in the bit-length of the output]

So the "Permanent is in VNP but not VP" question is about **algebraic circuit structure**, not about Boolean computational power. As a Boolean function, Permanent is in P (hence in P/poly, hence captured by 𝓔 + 𝓓).

**Verdict.** Algebraic complexity is a **structural refinement** of circuit complexity, not a new primitive in the Boolean framework. The 6-primitive framework handles algebraic computation by noting that VP ⊆ P/poly ⊆ 𝓓 + 𝓔.

### 3.7 Topological quantum computation — **REDUCES to BQP (same status as 3.2)**

**Construction.** Topological quantum computing (TQC; Freedman-Kitaev-Larsen-Wang 2002) uses anyons for fault-tolerant QC.

**Reduction status.** TQC is computationally equivalent to BQP: it can simulate any BQP computation, and any TQC computation can be simulated by BQP. [PROVEN — Freedman et al 2002]

**Verdict.** TQC has the same status as quantum (§3.2): UNKNOWN / CONDITIONAL on BQP ⊆ P/poly. Not an independent 7th primitive.

### 3.8 Indefinite causal order (quantum switch) — **REDUCES to BQP**

**Construction.** Quantum switch (Chiribella-D'Ariano-Perinotti-Lo Presti 2013): processes without definite causal order.

**Reduction status.** Quantum switch is in BQP. The "advantage" of indefinite causal order is a constant-factor (or polynomial) speedup over fixed-causal-order BQP for certain tasks (e.g., channel discrimination). It does not extend BQP to a larger complexity class. [PROVEN — Chiribella et al 2013; Oreshkov-Costa-Brukner 2012]

**Verdict.** Quantum switch REDUCES to BQP, which has the same status as §3.2. Not an independent 7th primitive.

### 3.9 Magic states — **REDUCES to BQP**

**Construction.** Magic state distillation (Bravyi-Kitaev 2005): non-Clifford resources enable universal quantum computation. Without magic states, Clifford-only computation is classically simulable (Gottesman-Knill theorem).

**Reduction status.** Magic states are a **resource** that unlocks universal BQP from Clifford-only (= classically simulable) computation. They do not extend BQP to a larger class. [PROVEN — Bravyi-Kitaev 2005; Gottesman-Knill]

**Verdict.** Magic states REDUCES to BQP, same status as §3.2. Not an independent 7th primitive.

### 3.10 Hypercomputation (Zeno, infinite-time TM) — **EXCLUDED by A5**

**Construction.** Zeno computation (using quantum Zeno effect for infinite computation in finite time); infinite-time Turing machines (Hamkins-Lewis 2000); real computation (Blum-Shub-Smale).

**Reduction status.** Hypercomputation models compute functions that are NOT TM-computable (e.g., decide halting, decide first-order truth over ℝ). They escape any framework based on A1 (Church-Turing). [PROVEN — standard result]

**Physical realizability.** Hypercomputation requires **infinite precision** (e.g., real-number arithmetic in BSS) or **infinite time in finite physical duration** (Zeno). Both are excluded by A5 (physical realizability = bounded resources). [HYPOTHESIZED — no known physical mechanism supports hypercomputation; see Davis 2006 "Why there is no such discipline as hypercomputation"]

**Verdict.** Hypercomputation is excluded by A5 (and by A1). Not a 7th primitive within the framework.

## Part 4 — Strongest Surviving Theorem

### 4.1 The 6-primitive theorem (conditional)

**Theorem (6-primitive closure, v6.44).** *Under assumptions A1, A5, A6, A7 (see Part 5) — specifically: (A1) the Church-Turing thesis; (A5) physical realizability (no unbounded provers, no hypercomputation); (A6) BQP ⊆ P/poly; (A7) worst-case complexity is the relevant measure — every practical computational advantage on every standard resource axis reduces to one of {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓}.*

[CONDITIONAL ON A1, A5, A6, A7]

**Discussion.** This theorem is **strictly stronger than v6.42** because it absorbs the v6.43 counterexample (Counterexample A: undecidable unary language now in 𝓟 via 𝓓). It is also strictly stronger because it removes the v6.42 assumptions "BPP = P" (replaced by Adleman's theorem) and "no non-uniform advice" (replaced by adding 𝓓 as a primitive).

However, it still relies on A6 (BQP ⊆ P/poly), which is **open**. If BQP ⊄ P/poly, the 6-primitive theorem fails and a 7th primitive (Quantum) is required.

### 4.2 The 7-primitive theorem (more robust)

**Theorem (7-primitive closure, v6.44).** *Under assumptions A1 and A5 — specifically: (A1) the Church-Turing thesis; (A5) physical realizability (no unbounded provers, no hypercomputation) — every practical computational advantage on every standard resource axis reduces to one of {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓, 𝓠}, where 𝓠 is the Quantum primitive (defined as: any algorithm using a quantum circuit of polynomial size, equivalent to BQP).*

[CONDITIONAL ON A1, A5]

**Discussion.** This theorem is **strictly more robust than the 6-primitive theorem** because:
- It does NOT require A6 (BQP ⊆ P/poly). If BQP ⊆ P/poly, then 𝓠 reduces to 𝓓 and the 7-primitive theorem reduces to the 6-primitive theorem. If BQP ⊄ P/poly, then 𝓠 is a genuine 7th primitive and the 7-primitive theorem holds with 𝓠 included.
- It absorbs candidates #7 (TQC), #8 (quantum switch), #9 (magic states) automatically — all reduce to 𝓠 by standard results.
- It still requires A5 (to exclude unbounded provers, #3) and A1 (to exclude hypercomputation, #10).

**Primitive count.** The strongest surviving framework has **7 primitives**: {𝓒, 𝓐, 𝓢, 𝓥, 𝓔, 𝓓, 𝓠}.

But an SAT-oracle is excluded by A5 (it would solve NP-complete problems, requiring non-physical computation). [CONDITIONAL ON A5]

- **Quantum advice** (BQP/qpoly): quantum advice (advice state of polynomial qubits) is known to satisfy BQP/qpoly ⊆ PP/poly (Aaronson 2004) and BQP/qpoly ⊆ QMA/qpoly. Whether BQP/qpoly = BQP/poly (i.e., quantum advice helps over classical advice) is OPEN. If they differ, quantum advice is a candidate 8th primitive. [UNKNOWN]
