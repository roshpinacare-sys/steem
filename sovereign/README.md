# SAOS-NET — הרשת-הריבונית שלנו

> "שהכל יושב על הרשת שלנו" — זו הרשת. הקרקע הוכנה בשלבים,
> ממשיכה לרוץ מקביל בזמן שהאימפריה על Steem/Hive, וכל צ'קפוינט שלה
> מעוגן על-השרשראות-המארחות כראיה-ציבורית.

## מה זה

SAOS-NET v0 היא **שרשרת-צל מעוגנת** (shadow anchored chain):

- **מצב דטרמיניסטי** — מכונה אחת קטנה (`core/kernel.cjs`): 12 פעולות,
  אריתמטיקה-שלמה, state-root = sha256 קנוני. אותו קלט = אותו עולם, תמיד.
- **ג'נזיס נגזר-מראיות** — המצב ההתחלתי אינו המצאה: הוא נגזר חי מה-replay
  של הדקס/עגונים/הצי שכבר מאומתים על השרשראות המארחות.
- **הסכמה מעוגנת** — בלוקים נבנים מקומית; כל 12 בלוקים צ'קפוינט
  (stateRoot) נעוגן על Steem+Hive; **החיילים הם הולידטורים** — כל אחד
  חותם attest במפתח-שלו; quorum = 3.
- **ערך זורם** — הפעולות הן בדיוק הכלכלה שכבר חיה על האוטובוס:
  transfer/pay/ספר/בריכה/עגונים/תשואה — אותם חוקים, עכשיו ברשת-שלנו.

## עץ-הקבצים

```
sovereign/
  README.md              ← אתה כאן (חוקה)
  spec/CHAIN_SPEC.md     ← המפרט הקבוע (יחידות, ops, גז, הסכמה, וקטורים)
  core/kernel.cjs        ← המנוע הדטרמיניסטי + self-test (--selftest)
  genesis/derive-genesis.cjs  ← נגזרת-ג'נזיס חיה מה-replay (--live)
  genesis/genesis.json   ← הג'נזיס (נוצר-ונעוגן; genesisHash בפנים)
  node/saosnet.cjs       ← הצומת: --boot / --beat / --selftest
  node/state.json        ← מצב-ריצה (נוצר בריצה; נעקב ב-git)
  recovery/manifest.json ← מניפסט-תחייה (מה צריך כדי לעלות מחדש)
  recovery/REINCARNATION.md   ← ספר-התחייה (מהתחלה מסביבה-ריקה)
agent/phoenix.cjs       ← בודק-תחייה: --check (הכל-מחובר/מאובטח/מעוגן?)
```

## מסלול-ההקמה (מדורג — הכל מוכן מראש)

0. **shadow** — הצומת חי, צ'קפוינטים מעוגנים, חיילים חותמים ← **עכשיו**
1. **mirror** — כל אירוע-אימפריה חי הופך tx בזמן-אמת (הקוד מוכן: `mirrorTxs`
   ב-`saosnet.cjs` קורא את מצב-הלולאות וממפה אירועים חדשים)
2. **economy** — תשלומים אמיתיים זורמים ברשת-שלנו; המארחות = עיגון בלבד
3. **full** — ראשים מתחלפים (החיילים מפיקי-בלוקים), UI משלנו על הרשת

## כלל-ברזל

1. **המפרט קודם לקוד** — שינוי ב-CHAIN_SPEC.md = fork מתועד.
2. **וקטורי-הקביעות קדושים** — `--selftest` חייב לעבור בכל מכונה; סטייה = fork.
3. **אין מפתחות כאן** — ה-sovereign/ נקי-מסודות לחלוטין; החתימה תמיד מקומית
   מ-agent/keys (שלא ב-git).
4. **עיגון = ראיה** — כל צ'קפוינט עם txid מאומת; צ'קפוינט-בלי-עיגון = pending.
5. **הכל ב-repo** — כל קובץ-חדש נדחף; gitkeeper שומר; phoenix מוודא.
