# REBUILD-RUNBOOK — תרגיל שחזור ריבונות (Recovery Runbook)

**מטרה**: הוכחה ניתנת-לחזרה שהאורגניזם ניתן לשחזור מהמאגר המרוחק **בלי** סנדבוקס זה — על ידי תהליך בלתי תלוי.
**מקור**: ביקורת R213 (verdict B) — שחזור הוכח ידנית; ראנבוק זה הופך את ההוכחה לניתנת-לביצוע בפקודה אחת.
**חוק**: **אסור הפעלה** — התרגיל מוכיח קבצים+תלויות בלבד. אף הפעלת מנוע, אף טעינת מפתח חתימה, אף גע בכספים.

## קלט נדרש (מה חייב לשרוד את מות הסנדבוקס)

| קלט | מקור אם הסנדבוקס מת | בעלים |
|---|---|---|
| PAT תקף (fine-grained, `repo` read) | `pat.rar` + סיסמתו — **בידי האופרטור בלבד (צ'אט 2026-10-05); אין שכפול כאן לפי סעיף 8 של החוק** — או PAT חדש מהאופרטור | אופרטור |
| שם המאגר/ענף | `roshpinacare-sys/steem` @ `saos-cockpit` (קנוני דה-פקטו — ראה audit/r213/VERDICT.json) | מתועד במאגר |
| Bun runtime | מותקן בכל סנדבוקס חדש | סביבה |

## ביצוע

```bash
# תרגיל מלא (מקומי, PAT ב-.secrets):
recovery/rebuild.sh

# שחזור בלתי תלוי (סנדבוקס חדש / מכונה חדשה):
SECRETS_FILE=/path/to/github.pat recovery/rebuild.sh
# משתנים אופציונליים: REPO, BRANCH, WORK
```

## מה התרגיל מוכיח (ומה לא)

1. **מוכיח**: clone מהמרוחק; tip; 9 ארטיפקטי ביקורת קיימים ו-VERDICT.json תקין; עץ מצב מנוע + worklog + כניסת מנוע קיימים; תלויות מותקנות frozen-lockfile; כל JSON מצב תקין.
2. **לא מוכיח (מתועד)**: מצב חי מהרגע האחרון (Git מייצג רק את רגע הדחיפה — ראה VERDICT currentCaveat); טעינת credentials (בכוונה — חוק אי-הפעלה); המשך זהות תהליך.

## אחרי התרגיל — צעדי הפעלה (אופרטור-גייט בלבד, מחוץ לסמכות מכונה)

1. `bun install` בשורש וב-`mini-services/saos-engine`
2. תיקון `.env` (DATABASE_URL מוחלט — ראה audit/r213/STATE-INTEGRITY.json)
3. הצבת `.secrets/headcorner.key` (חתימה) — **רק בהוראת אופרטור מפורשת**
4. `bun run dev` במיני-שירות המנוע; בדיקת `/health` + `/exec-status` (verdict=VERIFIED)
