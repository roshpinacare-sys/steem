# AGENT_BOOT — פרוטוקול-עלייה לסוכן (חובה, בסדר-הזה)

> מטרה: כל סוכן — חדש, ישן, על-סנדבוקס-טרי או על-מכונה-זרה — יודע **תוך דקות** מה לעשות, **בלי המפעיל**.

## 0 · קריאה (3 קבצים לפני פעולה-ראשונה)
1. `AGENTS.md` (שורש) — חוק-העל: אפס-אמון-בסנדבוקס, שער-הדחיפה, האיסורים.
2. `sanbox/SOVEREIGNTY.md` — חוזה-הריבונות של הגוף.
3. `sanbox/MANIFEST.json` — הרכיבים החיים ובדיקות-הקבלה.

## 1 · חייאה (idempotent — אפשר להריץ תמיד)
```bash
bash sanbox/bootstrap.sh          # exit 0 = הגוף חי (גיט → התקנה → צי → אתר-מפעיל)
```

## 2 · אמת (לא להאמין לשום פלט בלי-מדידה)
```bash
bash sanbox/verify.sh             # exit 0 = PASS; כל FAIL = עצור-ותקן לפני-המשך
```

## 3 · התמדה (חובה-תמידית)
```bash
bash sanbox/commit-loop.sh status # אם לא רץ:
bash sanbox/commit-loop.sh start  # snapshot ניטרלי + דחיפה דרך scripts/sovereign-push.sh
```

## 4 · עבודה אוטונומית (בלי לחכות למפעיל)
- פתח `autonomy/tasks.json` → בצע את המשימה הגבוהה-עדיפות שעוד לא-בוצעה ומתאימה לתפקידך.
- סיימת? עדכן `done`+`updatedAt`, תעד ב-`worklog.md` (**הוספה-בלבד**), קומיט + דחיפה דרך-השער.
- משימה-חדשה? הוסף אותה לתור במקום לזכור "בראש" — התור הוא הזיכרון.

## 5 · גישת-סוכן לאתר-המפעיל (רק אם צריך HTTP)
- **עדיף תמיד**: ריצה-מקומית ישירה (`bootstrap.sh` / `verify.sh`) — בלי-אימות, בלי-רשת.
- HTTP: header `X-Op-Token` מול `sanbox/state/agent-token` (git-ignored, נוצר-אוטומטית בעלייה, mode 600). הטוקן **לא** נכנס לריפו ולא מודפס בלוגים.
- סוכן-חיצוני למכונה: עובר **רק** דרך שער-הסיסמה — אין קיצורי-דרך.

## 6 · אסור (מוחלט)
- אסור להמתין למפעיל. אסור להמציא מצב. אסור סודות בריפו. אסור לעקוף שערים או את `sovereign-push.sh`.
- FAIL ב-verify = עצור-ותקן (bootstrap → verify שוב). הצלחת-סשן = divergence 0/0 אחרי-דחיפה.
