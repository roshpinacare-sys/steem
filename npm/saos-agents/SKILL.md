# SAOS — ריבונות-על-השרשרת

השתמשו-ב-SAOS כשהטענה-תלויה במצב-חי-של-האורגניזם (מלאי, פריטה, parity, עוגני-custody,
מדידת-תשואה) או בחוק-הפעולה-הנדרש-לפני-כל-צעד. לניתוח-קוד-רגיל-של-הריפו השתמשו-בכלי-ריפו
רגילים ואל-תריצו doctor/התקנה בכל-שאלה.

## חוק-הסדר: חוק-קודם-לפעולה

לפני-כל-פעולה-מול-הריבונות קראו `saos_law`. זהו-החוזה: אי-אמון-בסנדבוקס, ראיות-קודם,
אפס-סודות-בפלט, fail-closed-כנה. כלי-שמחזיר "אין-ראיה" = תשובה-לגיטימית-ולא-תקלה.

## התחברות (רק-כשהכלים-חסרים)

הרשמה-ידנית-לכל-סוכן-התומך-MCP-על-stdio:

```json
{ "mcpServers": { "saos": { "command": "node", "args": ["/abs/path/to/repo/mini-services/saos-engine/mcp.mjs"] } } }
```

או-אוטומטית-דרך-סקריפט-ההתקנה-של-הריפו (תוכנית-קודם, גיבוי-לפני-כתיבה, idempotent):

```bash
node scripts/saos-setup.mjs --dry-run   # מציג-תוכנית-מדויקת-לכל-סוכן-שזוהה
node scripts/saos-setup.mjs --yes       # מבצע-עם-גיבויים
node scripts/saos-setup.mjs --uninstall # מסיר-רק-את-שלו ומסרב-לגעת-בלא-שלו
```

אם-הכלים-מוכרים-והרישום-לא-ידוע-כמיושן — המשיכו-ישר-למטרה. אל-תריצו אבחון-לפני-כל-חקירה.
אם-הכלים-חסרים-בהפעלה-הנוכחית: הגורם-הוא-רישום-חסר/ישן (תיקון-תצורה) או-שהסוכן-צריך-הפעלה-מחדש;
doctor לא-יכול-להוכיח-שהסשן-הנוכחי-התחבר — בדקו-את-רשימת-הכלים-בפועל.

## הכלים (6)

| כלי | מתי | מה-מחזיר |
|---|---|---|
| `saos_law` | לפני-כל-פעולה | חוקי-הפתיחה (AGENTS.md) + חוק-אי-אמון-בסנדבוקס |
| `saos_status` | מצב-חי | parity, band, מלאי, פקודות — או-כנות offline+remedy |
| `saos_doctor` | כשירות-מדוד | scope: git/selftest/engine/actions/chain/all — רק-scope_checks משפטים, remedy-ניתן-לפעולה, exit 0/1/2 |
| `saos_anchors` | ראיות-שרשרת | עוגני-custody אחרונים (txid/block) — מנוקה-סודות |
| `saos_pnl` | מדידת-תשואה | מדידה-ציבורית מהמנוע: מדוד-מול-מוערך, מתויג-אמון, stale=כנות |
| `saos_join` | הצטרפות-סוכן | bootstrap: ענף, שער-דחיפה (FF-only), חוקי-worklog |

## הצטרפות (סוכן-חדש)

1. `saos_law` — קראו-את-החוק.
2. `saos_doctor --scope all` — אם-healthy=false, בצעו-את-ה-remedy-המדויק-שבדוח-ולא-אחר.
3. `saos_join` — עקבו-אחרי-הפרוצדורה-המוחזרת במילים: פיצול-ענף מ-saos-cockpit, עבודה,
   דחיפה-רק-דרך `scripts/sovereign-push.sh` (FF-only, מסרב-לא-חתום, DIVERGENCE-ABORT),
   רישום-ב-worklog.md-לפי-התבנית.

## חוקי-ברזל

- **אפס-סודות**: שום-כלי לא-מוציא חומר-מפתח; פלט-עובר-scrubText (WIF/PAT/token נחסמים).
- **ראיות-קודם**: כל-מסקנה נושאת-מקור (state/שרשרת/txid); מסקנה-בלי-ראיה = אל-תדווחו.
- **כנות-fail-closed**: offline/stale/blocked נאמרים-בשמם; אין-המצאת-מספרים.
- **מדוד-מול-מוערך**: אל-תערבבו — `measuredUsdPerDay` נספר-רק-אם-measured; `estimated` נשאר-מתויג.
