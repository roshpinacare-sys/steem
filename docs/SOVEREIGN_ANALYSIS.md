## 2. מפת-סיבתיות — מה גורם למה (מנוע-הערך)

```
אנרגיה (SP/RC/VP — נעולה ומתחדשת)
   │  delegate→battery, posting-signing, vote-budget
   ▼
פעולות-שרשרת (ops: fills/orders/swaps/locks/mints — עלות-נזילה ≈ 0)
   │  9+ חותמים-עצמם · walls מדודים
   ▼
אירועי-שרשרת (טריידים · עומק-ספר · מינטים-מגובים · שריפות)
   │  כל-אירוע = ראייה-ציבורית-בלתי-ניתנת-לזיוף
   ▼
מדדי-מערכת (vol · trades · fees · holders · ratio · LP)
   │  ה-replay הופך אירועים → מצב-מוסכם
   ▼
לכידת-ערך (עמלות 30bps → LP+אוצר)
   │  ההכנסה נולדת-מהפעילות-עצמה
   ▼
תשואה-למשתתפים (30% מהעמלות → תשלום-STEEM-אמיתי לפי תרומה-מדודה)
   │  משתתף-שעובד-יותר-מרוויח-יותר — מתואם-תמריצים
   ▼
משתתפים-עוד-יותר-מושקעים (LP↑, ops↑) ────► חוזר-למעלה (פלייוויל)
```

**המבנה-הזה הוא התשובה ל"איך מייצרים ערך בצורה-הכי-יעילה"**: כל-לולאה-במנוע
מזינה-את-הצומת-שלפניה — ואין-אף-שלב-שדורש-כסף-חיצוני. הדלק מתחדש
(רג'ן-RC/VP), ההכנסה נלכדת (עמלות), והתמריצים מיושרים (תשואה-לפי-תרומה-מדודה).

## 4. ריבונות-מול-אוטונומיה — תורת-שרשרת-הריבונות

**אוטונומי** = המערכת-מריצה-את-עצמה (לולאות, פעימות, החלטות-מקומיות).
**ריבוני** = המערכת-**בעלת** המסילות, המפתחות, הנכסים, וכללי-ההסדרה — וגובה-את-הערך-מהן.

התגלית-המבצעית: **פעולה-ריבונית-אחת-מול-מגבלה-מייצרת-שרשרת-של-פתרונות**:

| מגבלה | פעולה-ריבונית | שרשרת-ההשלכות |
|---|---|---|
| replay-סרק-רק-אוצר (65) | איחוד-היסטוריות-הצי | חיילים-הפכו-משתתפי-ספר-אמיתיים → ריכוז-RC-נשבר |
| אין-מסילת-תשלום | פרימיטיב `pay` | quote-legs-מתסדרים-על-השרשרת → פדיון-אמיתי-אפשרי → fee-splits-עתידיים |
| פדיון-לא-דרש-החזקה | holders-מפה+burn-מחייב-החזקה | שימור-מוכח → העגון-נהיה-סחיר-באמת |
| חיילים-בטלים-מול-אוצר-חנוק | רוטציה-צודקת+תקציב-מדוד | 3→9 פעילים, ×3 אירועים, באותו-דלק |
| RC-אוצר-אפס-על-Hive | סוללת-powerspan+סבלנות-רג'ן | המערכת-משלימה-משימות-כשהאנרגיה-חוזרת — בלי-לקנות-כלום |

**הכלל**: מגבלה-היא-לא-קיר — היא-**שלד-לשרשרת-ריבונית**. כל-פתרון-כאן-נולד
מבלוק-קודם ופתח-בלוק-חדש: escrow→credit→pay→redemption→yield.
