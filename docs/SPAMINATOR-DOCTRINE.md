## 1 · מי זה הספאמינטור ומה-הוא מחפש

הספאמינטור (@spaminator) וסורקי-הניקיון (steemcleaners-ודומיו) מדגילים/מדווחים על-דפוסים — לא על-דעות:

| דפוס | למה זה נתפס | החוק שלנו |
|---|---|---|
| גניבה/סחיטה-מחדש (spun) | אותו-מבנה-משפטים, מילים-מוחלפות | מקוריות-מלאה; מקורות-מצוטטים-בלינק |
| פוסטים-רזים (<300 מילים) | אין-ערך-מדוד | **MIN_POST_WORDS=300** מקודד-בשער |
| מונוקולטורה | 3-חשבונות-אותה-כותרת-ביום = טביעת-בוט | **MONOCULTURE-VETO**: titleSimilarity≥0.5 → וטו |
| הצפת-קצב | פוסטים-ברצף-מכני | maxPostsPerDay=1 לחשבון · קצב-אנושי-מתוזמן |
| הצמדות-רגעית | שני-חשבונות-באותה-דקה | **PACING-LAW**: פעולה-אחת-לחשבון-למחזור |
| טבעות-הצבעה-עצמיות | מעגל-סגור = הדרה-מהשוק | pair-guard על-אמת-השרשרת; תמיכה-הדדית מדודה-ולא-עיוורת |
| תיוג-ניצול | 5-תגים-חמים-לא-רלוונטיים | תגים-רלוונטיים-בלבד, מקסימום-5 |
| מילוי-קישורים | רשימת-לינקים במקום תוכן | spamVerdict: link-stuffing → חסימה |
| חקירת-ביטויי-פיתיון | "get rich", "click here" | רשימת-ביטויים-אסורים ב-spamgate |

## 2 · השערים שלנו (מקודדים — לא נוהג-רצוי)

1. **thin-veto** — טיוטה-רזה נשחטת-בשידור (content.mjs/army-social.mjs)
2. **monoculture-veto** — השוואת-כותרות מול-20-הפרסומים-האחרונים
3. **spamgate** — 3-מסילות-השידור (publish/fleet-comment/reply) כולן עוברות את-אותו-חוק
4. **pair-guard** — get_content_replies על-ההורה: הקול-שלנו-כבר-שם ⇒ נסיגה
5. **רעננות-לשונית** — replyFresh: דמיון->0.34 מול-מה-שנאמר-היום ⇒ נפסל
6. **WARM-UP-LAW** — זרעי-רנדומליזציה ראשונים-נזרקים (התפלגות-מתנגשת)
