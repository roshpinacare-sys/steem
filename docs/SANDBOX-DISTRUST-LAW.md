## סעיף 1 — הגדרות
1. **אמת** = קוד-חתום ב-`origin/saos-cockpit` + שרשרת-ציבורית (Steem, צומת-כלשהו) + תשובה-חיה-נמדדת.
2. **סנדבוקס** = כל-סביבת-הרצה מקומית/ארעית. נמחקת ומשוחזרת-מצלם-עתיק ~5×/יום. **מעמדה: מטמון-ביצוע בלבד. אינה מקור-אמת, אינה מקום-אחזקת-סודות, אינה זיכרון.**
3. **ריבונות** = היכולת לבצע (שחזור → בדיקה → חתימה → פרסום → עיגון) מהגיט-בלבד, בכל-זמן, גם-אחרי-מחיקה-מלאה.

## סעיף 2 — דיני-אמון
1. אסור לסוכן/כלי להסתמך על מצב, זיכרון, pid, לוג או טענה שקיימים-רק-בסנדבוקס.
2. כל-טענת-"יש לנו X" חייבת-הוכחה אחת-מ: (א) קובץ-חתום-בגיט (`git show HEAD:…`), (ב) עסקה-על-השרשרת-הציבורית, (ג) מדידה-חיה-עכשיו.
3. סתירה בין-זיכרון-מקומי לבין-הגיט/השרשרת → הגיט/השרשרת זוכים, תמיד.
4. כל-סשן נפתח באפס-אמון: `fetch + reset --hard origin/saos-cockpit` + `divergence-check.sh` + `selftest.mjs`.

## סעיף 3 — דיני-סודות
1. אסור שלמפתח-חתימה-או-מפתחות-פעולה תלות-חיים בכרינג-סנדבוקס. מקום-המגורים המאושר: GitHub Secrets (ל-runner) / אחסון-חוץ-מאושר-מפעיל.
2. בעץ-הגיט מותרים **מפתחות-ציבוריים בלבד** (`signing/*.asc` — PUBLIC BLOCK בלבד; נבדק R241).
3. אובדן-מפתח-סודי = אירוע-ריבונות: מתועד-מיד ב-worklog + בביקורת-הסבב, ה-custodian מוחזק-כבוי עד-השבת-יכולת, וקומיטי-גוף-לא-חתומים נאסרים (רק-checkpoint-ניטרלי + תיעוד-סיבה).

2. **דופק-חיצוני (R280)**: המארח-החוץ הוא המאגר-הציבורי `roshpinacare-sys/saos-runtime` (דקות-Actions-חינמיות) — `sovereign-runtime.yml` נושא-את-שעון-הרשת בעצמו: כל-מחזור (הצלחה-או-כשל) מפעיל-את-הבא אחרי-15-דק (פולס-עצמי, קצב-קבוע ~20-25-דק) ו-cron-שעתי הוא-גיבוי-מחיה-עצמית אם-השרשרת-מתה. מחזור-אחד: clone-מסונן-blobs של-ענף-הרשומה → selftest → פרובת-עוגן-שרשרת מול-HEAD → שיחת-הצי-על-השרשרת (guards-R274/R275) → DEX-takeover כשהעוגן-המקומי-מזדקן → החזרת-state ל-`saos-cockpit` (FF-only). כשל = אזעקה-גלויה בלוח-ה-Actions-הציבורי. רקע-מדוד (2026-10-08): מתזמן-GitHub הוריד cron-של-30-דק לפערים-של-~7.5-שעות, וה-workflow-הפרטי `sovereign-cycle.yml` מת-על-קיר-חיוב-המאגר-הפרטי (ריצות-ריקות-מ-לוגים) — לכן-הדופק-עבר-למארח-הציבורי-עם-הפולס-העצמי, וה-`sovereign-cycle` נשאר-כלי-אבחון-בהזמנה-בלבד.
