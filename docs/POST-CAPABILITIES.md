# יכולות-הפרסום על השרשרת (R262)

> שאלת המפעיל (2026-10-08): "צריך להבין מה אפשר לעשות עם פוסט, אם אפשר HTML,
> עד איזה רמה, מה נוכל לעשות בפוסטים" — התשובה המדודה, והחוק שנגזר ממנה.

## העיקרון: השרשרת שומרת הכל, החזית מסננת

גוף הפוסט נשמר על השרשרת **גולמי** (bytes מלאים, לנצח). מה שהקורא רואה נקבע
על-ידי ה-frontend (steemit / peakd / ecency / hive.blog), שכולם מרנדרים
Markdown + תת-קבוצה בטוחה של HTML ו**מפרקים** כל סקריפט. לכן החוק שלנו:
כותבים רק את מה שמרנדר בכל החזיתות — מה שנחתך הוא רעש, לא יכולת.

## מה כן עובד (המטריצה המאושרת)

| יכולת | איך | איפה מרנדר |
|---|---|---|
| כותרות | `#` עד `####` | הכל |
| הדגשות | `**bold**`, `*italic*`, `~~strikethrough~~` | הכל |
| רשימות | `-` / `1.` (כולל מקוננות) | הכל |
| טבלאות | Markdown pipes או `<table><tr><th><td>` | הכל |
| ציטוטים | `>` (כולל קינון) | הכל |
| בלוקי קוד | ` ``` ` fenced עם שפה | הכל |
| קווי הפרדה | `---` או `<hr>` | הכל |
| מרכוז תוכן | `<center>...</center>` | הכל |
| כיתוב עליון/תחתון | `<sup>`, `<sub>` | הכל |
| **אזור מתקפל** | `<details><summary>כותרת</summary>תוכן</details>` | הכל (TL;DR / העמקה) |
| תמונות | `![alt](https://...)` — אצלנו: upload.wikimedia.org בלבד + קרדיט | הכל |
| קישורים | `[טקסט](https://...)` | הכל |
| עיגולים/רשימות-משימות | `- [ ]` / `- [x]` | רוב החזיתות |
| תגיות | `json_metadata.tags` (עד 5 ב-Steem, 10 ב-Hive; הראשונה קובעת את הקהילה/ערוץ) | הכל |

## מה נחתך (לעולם לא נשלח)

- `<script>`, `<style>`, `<iframe>`, `<object>`, `<embed>` — נמחקים בכל חזית.
- מאפייני `on*` (onclick וכו'), `javascript:` URLs — נמחקים.
- מאפיין `style` — ברוב החזיתות נמחק; לא נבנה עליו.
- תמונות מ-http:// (לא https) — חלק מהחזיתות חוסמות.

## החוק שלנו (FORMAT_LAW ב-content.mjs)

1. Markdown קודם הכל; HTML רק מתת-הקבוצה הבטוחה לעיל.
2. מבנה הוא תבלין ולא המנה: טבלה אחת להשוואה אמיתית, collapsible אחד
   להעמקה-אופציונלית, pull-quote ממורכז לכל היותר פעם אחת.
3. תמונות: Wikimedia Commons בלבד, עם שורת קרדיט חובה (artist, license,
   קישור לדף הקובץ) — בדיוק כמו ש-illustrate.mjs מחייב לפוסטים.
4. החוק מוזרם לחדר-הכתיבה (bridge `formatLaw`) ונאכף בקוד טהור בשערי הפרסום.

## למה זה חשוב לראות טוב

פוסט מסודר הוא מכפיל אמון: טבלה = המספרים נבדקו; collapsible = מכבד את
זמן הקורא; תמונה חוקית עם קרדיט = יושרה. זה חלק מ"מקצוענים וקהילתיים"
שהמפעיל הורה — ומהפוסטים עצמם ידברו על זה (הנושאים `on-chain-publishing`
ו-`post-craft` נכנסו למאגר הנושאים של הצי).
