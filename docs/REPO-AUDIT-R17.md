### 3.1 · key-broker היה כבוי מאז-אתחול הסביבה — **תוקן**
- הסניפט-הפלטפורמי לא מריץ אותו; באתחול 17:48 הוא קרס ביצירת-הטוקן-הראשונה (חד-פעמי)
- **תוקן**: הועלה ידנית → `/health` = ok · 8 דלתות · families sov+legacy
- **שורש-הפתרון כבר היה במקום**: הגרדיאן מחזיק ווטשדוג-ברוקר (117k) שבודק תקינות בכל-טיק ומקים אותו אוטומטית — אומת-חי (ניסיון-ספאון תקין → EADDRINUSE מול המופע-החי = התנהגות-נכונה)
- הטוקן יציב (z:z · 0600 · `agent/keys/` מוזנח-מגיט) → אין-מוקש לאתחול-הבא; הברוקר יקום-עצמאית

### 3.2 · lint מלא-ריפו נחתך ב-SIGKILL (מגבלת-זיכרון-סביבה)
- `bun run lint` על כל-העץ (כולל docs/scripts) אוכל-זיכרון-יתר
- **פתרון**: `bunx eslint src` ממוקד — **עובר נקי, 0 שגיאות**. בסביבה-זו להריץ lint ממוקד-src

### 3.3 · משקל-הריפו: חבילת-גיט 202MB — מוסבר, לא-נוגעים
- ההיסטוריה נושאת ~10 בלובים של 66-73MB של `sovereign/node/chain-archive.jsonl` — שריד-הבאג-הישן (היומן-החי צמח ~86MB/יום ונדחף בשלמותו כל-מחזור)
- **הבאג תוקן מזמן (117p5)**: היומן-החי אינו-נעקב (4.4MB על-הדיסק בלבד); ההישרדות נוסעת בחותמת-דחוסה (`chain-archive-seal.jsonl.gz` + seal-state) — אומת שהנעקבות-תקינה

- **החלטה-דוקטרינית**: ההיסטוריה קפואה וקדושה — אין-שכתוב-היסטוריה, אין-force-push. המשקל הוא-מחיר-הביטחון, והוא-יציב (לא-צומח יותר)
