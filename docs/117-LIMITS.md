## 4. שער-האמנזיה — מלחמת-הכותבים (נתגלה-ונרפא-היום-בחיים)

**המגבלה (נמדד-היום):** כותבים-מרובים (דמון-תושב + פעימות-guardian + inject) + דמון-שרד-מהדורת-קרנל-ישנה = ליניאגה-שכחה: הדמון-הישן (בלי tx.raw/raw-pool) בלע-את-בלוק-הזריעה-מבחינת-מצב, ה-anchor-בגובה-אחד אימת-את-הליניאגה-העיוורת, וה-dedup last-wins חיזק-אותה. הבריכה-נעלמה-מהסנפשוט בעודה-חיה-בארכיון.

**הפתרון-שנבנה (117c):**
- **חוק-הדם (bloodline-law)** ב-beat-restore: סנפשוט מתקבל רק אם כל-הבלוקים-מעליו-בארכיון יוצרים רצף-prevHash אחיד; שבר-אחד = דחייה-כנה → replay-מלא (הוכח-חי: root נדחה על שבר-ב-h51151 → replay-מלא שחזר-הכל-בדיוק).
- **תעודה-גולמית (raw:true)** ב-pool_xAdd/pool_x — יחידות-ספר-שלמות בלי-דיוק-µ (הכרחי לננו).
- **דיסציפלינת-הקרנל:** כל-שינוי-קרנל = הפסקת-כל-דמוני-saosnet לפני-inject ראשון (נזכר-ב-worklog-116 ונאכף-היום-בפועל).

**שארית-סיכון-מתועדת:** state-root.json נשאר-זקן (h38,872 מול ראש-52,9xx) — הקידום-נדיר; מסוכן-רק-כאיטות-זיכרון-כפולה. תיקון-עתידי: קידום-שורש כל-N-צ'קפוינטים.

**✅ נסגר-ב-117k:** קידום-שורש-אוטומטי מומש — כל-50-צ'קפוינטים (≈600-בלוקים) במסלול-החי (maybeCheckpoint) + אותו-דבר ב-boot; כתיבה-אטומית במבנה-ש-restore מאמת (אומת-מול-ארכיון-אמת). השורש-לא-יתיישן-יותר.

## 5. µ()-קשיחה בפעולות-בריכה (דיוק-ננו)

**המגבלה:** הקרנל מכפיל amountA/B/inAmt ב-1000 (µ) — נכון לסמלי-µ, שובר-ננו (WETH 1e9): יחידות-אנוש לא-מייצגות-ננו.

**הפתרון-שנבנה:** תעודה-גולמית `raw:true` — יחידות-ספר-כמות-שהן. **חובה-עתידית:** deposits.cjs מזריע-בריכות-ננו עם-amountA-ביחידות-ספר בלי-raw → יתומחר ×1000 כשההפקדה-האמת-הראשונה-תנחת. לתקן-לפני-ההפקדה-הראשונה (שורת-קוד: הוספת raw:true ב-poolTxs).

**✅ נסגר (נמדד-ב-117j):** raw:true כבר-במקום (deposits.cjs:188, מאז-117f) — המנדט-מומש. **ו-117k מוסיף:** מגן-minOut-אופציונלי-בקרנל-pool_x (replay-safe) + theswap-מבצע-עם-minOut-מהציטוט — פער-דקס-#1-מהסקר-נסגר.
