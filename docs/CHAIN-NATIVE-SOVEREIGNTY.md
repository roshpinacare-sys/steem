## אמת-היסוד על Steem (נמדד, לא נטען)
**אין חוזים-חכמים טיורינג-מלאים ב-L1** (SMT נגנז-היסטורית). מה שבאמת קיים — ומה שהמערכת שלנו בונה עליו:

| פרימיטיב-ילידי | מדד R242 | שימוש-ריבוני-אצלנו |
|---|---|---|
| `custom_json` (תור-הודעות-על-השרשרת) | ✅ SUPPORTED | כבר-בשימוש: עוגן `saos-git-custody-v1` — הגיט-מפורסם-על-השרשרת |
| `account_update` (multi-auth, משקלים-וספי-הצבעה) | ✅ SUPPORTED | ריבונות-מפוזרת: שום-סנדבוקס-יחיד-לא-מחזיק-כוח-מלא |
| `escrow_transfer` (חוזה-נאמנות-3-צדדים-אטומי) | ✅ SUPPORTED | עסקאות-מהימנות-עם-גורמי-חוץ — השרשרת-אוכפת |
| `create_proposal` (SPS/DAO — מימון-יומי-מהקופה-הציבורית) | ✅ SUPPORTED | מימון-עצמי-של-תשתית-מהרשת-עצמה |
| `delegate_vesting_shares` (שכירות-כוח-הצבעה) | ✅ SUPPORTED | הכנסה-פסיבית-על-השרשרת (vest-rental) |
| `set_recurring_transfer` (העברות-מתוכננות) | ❌ **לא-קיים-ב-Steem** (בניגוד-ל-Hive) | ייושם-אצלנו-כ-L2: מנוע-הזמנים-שלנו-על-גבי-פרוטוקול-custom_json |

**מסקנה-אדריכלית**: ה"חוזה-החכם" שלנו = **פרוטוקול-custom_json + מתורגמן-דטרמיניסטי-בגיט**. המצב-חי-על-השרשרת, ההיגיון-חתום-בגיט, וכל-צד-שלישי-יכול-לשחזר (replay) ולאמת. זו-בדיוק-הטכניקה-שבה-משתמש-Steem-Engine-לטוקנים.

## סולם-הריבונות — צעד-צעד

### L0 — כיום (מוכח R241)
גיט=אמת · סנדבוקס=מטמון-נמחק · Actions-דופק (ממתין-להפעלה-במאגר) · bootstrap-מוכח 427/427 מ-clone-טרי.

### L1 — "הרגל-המבצעת" האוניברסלית (נכנס-היום לגיט)
`scripts/sovereign-runner.sh` — רץ-על-**כל-מארח-חי** (VPS, מחשב-חבר, טלפון-Termux, CI): sync-אפס-אמון-מהגיט → בדיקת-חיות-עוגן → הצתת-מנוע-אם-מת → selftest-gate. **ה-runner טיפש; המוח-הוא-גיט+שרשרת.** ככל-שרגליים-רבות-יותר — כך-הריבונות-שורדת-יותר. GitHub-Actions הוא-רק-רגל-אחת-חינמית; הסקריפט-הזה-הופך-כל-לינוקס-לרגל.

### L2 — קונצנזוס-רגליים (מקורי-הרשת, ללא-תיאום-מרכזי)
כמה-רגליים-רצות-במקביל-בלי-להישבר: כל-רגל-מדווחת-חיות-ב-custom_json (`saos-runner-v1`), ו**מנהיג-תור-נגזר-דטרמיניסטית** מראש-הבלוק-בחלון (vrf-lite: hash(tip,epoch) mod N) — שתיקת-המנהיג = עוקב-נכנס. רגל-שרואה-DRIFT-מדווחת-על-השרשרת — אזעקה-ציבורית-שלא-ניתנת-להסתרה.

### L3 — חוזים-ילידיים לכלכלה (דורש-אישור-מפעיל — מימון/סמכות)
1. **SPS-Proposal לתשתית-ייעודית**: הצעה-על-השרשרת-מממנת-host-חי-קבוע (VPS ~$20-40/חודש) מהקופה-הציבורית — **עצמאות-כלכלית מ-GitHub ומכל-גורם-חוץ**. מנגנון: `create_proposal` (מדד-SUPPORTED) + הצבעה-מה-SP-שלנו-ושל-בעלי-ברית.
2. **Escrow לעסקאות-חוץ**: כל-עסקה-עם-צד-שלישי (מכירת-שירות/תוכן/סחורה) — `escrow_transfer` עם-סוכן-מהימן-מהקהילה. השרשרת-אוכפת-אטומיות; אפס-אמון-נדרש.
3. **Delegation-כשכירות**: השכרת-vests-לחיילים-חיים/שותפים-תמורת-תשלום-מתועד-custom_json — הכנסה-שנייה-מהיכולת-הקיימת.
4. **Multi-auth למפתחות**: ספי-משקל-על-active/posting (מפעיל+מערכת) — שום-מחיקת-סנדבוקס/גניבת-מפתח-יחיד-לא-מקרעת-שליטה. יושם-רק-אחרי-סבב-רוטציה-מאושר.

### L4 — חוזי-L2 (`saos-contract-v1`)
פרוטוקול-חוזים-על-custom_json: הצעה→אישור→ביצוע→הוכחה, כל-מעבר-מקודד-במתורגמן-החתום. מימוש-מקומי-של-מה-ש-recurring-transfers-נותנים-ל-Hive: לוחות-זמנים-למימון-חיילים, תשלומי-שכירות, תגמולי-ביצוע — הכל-ניתן-ל-replay-ואימות-ע"י-כל-צד.

### L5 — שיא-הריבונות: Witness-Node
השתתפות-בקונצנזוס-עצמו — ייצור-בלוקים, הצבעת-קונצנזוס, הכנסה-מהרשת-ישירות. דורש-מארח-קבוע-וסטייק-תמיכה — נכון-אחרי-L3.1.
