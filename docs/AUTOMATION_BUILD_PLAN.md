## 2. הבניות המדורגות (מה ליישם, בסדר)

### B1 — מפעל חשבונות RC · עדיפות 1 · הון: 0
הדרך היחידה לצמוח מאפס הון, עם ענף חי של 1,968 תביעות/יום ומלאי-מפעלים של מיליון חשבונות.
1. **מדידה (חוסמת-הכל):** חתימת `claim_account` אחת בקונסולה (פעולה מוכנה) → מדידת RC לפני/אחרי → עלות מדויקת במספרים.
2. **לופ תביעה בסוכן** — claim אוטומטי כשתקציב ה-RC מתמלא (דפוס upvu, 275/יום).
3. **`create_claimed_account` על-פי-דרישה** — פעולה חתומה-מוכנה חדשה בקונסולה + תמיכת סוכן (מלאי → חשבון חדש עם מפתחות שנוצרים מקומית).
4. **מונטיז** = החלטת-מפעיל חוץ-שרשרת: מכירה (מחיר-שוק לא אומת — פער-אמת) או צי-תתי-חשבונות (B4).
- סיכונים: אפס כסף; עלות RC בלבד. אוטומטי: מלא.
- **עדכון מדידה (20-a):** קיבולת ה-RC שלנו היא 0.19% בלבד מה-RC של justyy — טווח תביעות מוסק: **0.31–3.1 תביעות/יום** (לא "דפוס upvu 275/יום") · ערך-עליון של טיקט = account_creation_fee 3 STEEM ≈ **$0.313** (SBD≈$1) → **$0.10–0.98/יום עליון-גבול טהור** (לא מחיר-שוק; מונטיז אמיתי = rail חוץ-שרשרת, פער-אמת) · RC 100% · regen 1.8×10¹²/יום. **ממתין ל-A2** (עלות מדויקת = מספר במקום טווח).
- מדד: §EFFICIENCY_AUDIT (docs/EFFICIENCY_AUDIT.md · `.zscripts/efficiency_scan.py`).

### B2 — מנוע קוראציה אוטומטי · עדיפות 2 · posting-key בלבד
VP 98% רדום 6 חודשים = בזבוז; ההיסטוריה שלנו מוכיחה שהמנוע הזה הניב כאן 2.61% APR.
- בנייה: לופ סורק פוסטים חדשים (get_discussions_by_created) → ציון איכות (תגיות/אורך/מחבר) → הצבעה ב-5+ דק' (הימנעות חלון-מכירה מוקדם), מקסימום N הצבעות/יום, ללא self-vote.
- סקלטון כבר בסוכן (CURATION_ENABLED=false — כבוי עד אישור מפעיל).
- תוצאה כנה: ≈ $0.02–0.04/יום. לא משכורת — אבל אפס-סיכון, posting בלבד, וראשון שמנצל את ה-VP העצל.

### B3 — רייל תשלומים: transfer+memo router · עדיפות 3 · המשכורת
הראיה מהמפקד: 16,704 העברות/יום — זו מסילת-הסליקה בפועל של Steem (עמלה 0).
- בנייה: watcher פולט אופסים נכנסים → ניתוח memo (חשבונית) → ניתוב לביצוע אוטומטי → אישור ב-memo חזרה. escrow_* לעסקאות גדולות (ירוק בשרשרת = הבדלה, אך גם אין-הוכחת ביקוש — כנים).
- recurrent_transfer (~0 שימוש): מינויים נייטיביים לשירות — מוצר שאף אחד לא בנה.
- דורש: החלטת rail-play (RAIL_PLAY_BRIEF). ה-skeleton (watcher קריא-בלבד) כבר בסוכן.

### B4 — צי תתי-חשבונות (אחרי B1) · הכפלת תקציבים
כל חשבון חדש = תקציב RC משלו + זהות posting. הסוכן מנהל מפתחות מקומיים לכל פריט בצי (לא לשרת). מטרות: קוראציה מפוזרת, RC-פארם, אב-טיפוס שירות.

### B5 — משמר ההשכרות · זעיר
הסוכן בודק יומית את תשלומי upvu.bank ומתריע על פיגור. מגן על ה-4.15% הקיים.

### B6 — משחקי-השרשרת (steemx_ludo · hariraid · snakechamps) · תצפית
3-4 פרוטוקולי-משחק חיים התגלו במפקד. זהותם/כלכלתם חוץ-שרשרת (פער-אמת). פוטנציאל: RC-צריכה גדולה → שירותי-תשתית להם (B1/B3). לא לבנות עד מדידה נוספת.

### נדחה/נשלל (בלי איפור)
- **מייקר פנימי**: spread 0.166% × $13/יום = סנטים.
- **עדים/SPS**: ספים 13.8K/515K SP.
- **שוק delegate_rc**: אפס פעילות.

## 4. סדר-היום (שבוע)

1. A1 (2 דק') → A2 (חתימה אחת, Active, ואז נתק) — פותח את B1.
2. הפעלת B2 ניסיוני בסוכן (DRY_RUN → חי עם 5 הצבעות/יום) — מכבה את בזבוז ה-VP.
3. B5 משמר-השכרות בסוכן.
4. החלטת rail-play → B3 (ה-router כבר מגולל בסוכן).
5. אם A2 מראה עלות-RC סבירה → לופ-תביעה אוטומטי (דפוס upvu).
