# SAOS — מפת-הדרכים (ROADMAP)

> סדר-העדיפויות מעודכן אחרי Task 51 · הכל דרך proof-gate — אין-טענות-בלי-ראיה.

## 1. הג'נזיס-טוקן על Hive-Engine (הקרוב-ביותר)
- מדרגת-הערך רצה (run #23, 3/3 steps effect-verified) — **BEE 0/100**.
- ב-100 BEE: יצירת-SAOS-on-HE אוטומטית (precision 3, maxSupply 1e9, issue 1M, staking/delegation/market + seed ספר).
- דלק: he-ladder ממשיך (VKBT/CENT עברו; היתר RC-gated עד-רג'ן-Hive) + AFIT 16,968 במדרגה.
- **עובר-ביצוע**: conforms (13 טענות-קצה) ממתין-RC — ירוץ-אוטומטית.

## 2. מטריצת-בריכות (ה-Polygon-מודל)
- הבריכה SAOS:STEEM חיה (עמלות-נלכדות). **הצמד הבא: SAOS↔קרדיט-HE** כשהטוקן-ייוולד.
- Grid-MM סביב-המחיר-ההוגן (כבר-חי) — להרחיב-רשת-סלוטים ותקציב-פעימה.
- גרירת-ערך: חיילים-מנתבים עודף→נזילות (קיים) → **להכפיל-דרך-הצד-של-Hive** (Task 51 פתח-את-השער).

## 3. הצי — צמיחה-מנוהלת-דלק
- מפעל-דור-2 מטביע hcnova2+ כשהאוצר-מגיע-ל-80% RC (אוטומטי).
- כל-בוט-חדש נולד: דטרמיניסטי + עוגן-חילוץ + fleet_ping-ראשון + 50 SP נציבות.
- תפוקה-נוכחית: ≈3,200 ops/יום קיים-עצמי · פרץ-40/בלוק · **והצד-של-Hive עכשיו-פתוח**.

## 4. גיוס-הון (להזיז-את-המספרים)
- השלמת-הסולם: SWAP.HIVE→BEE (מדרגת-הג'נזיס) · AFIT-16,968 מדורג.
- אחרי-ג'נזיס: נזילות-SAOS-על-HE + צמדים-חיצוניים = **מקור-עמלות-ראשון-מחוץ-לאוטובוס**.
- HBD→HIVE (convert) — בלי-לגעת-ברצפת-האוצר.

## 5. ריבונות-מעמיקה (מתווה-Task 51)
- **שרדים-מתוזמנים**: worldlog השלם כאובייקט-חוצה-שרשראות (עכשיו: snapshot חד-פעמי → להפוך-לרציף-בדמון).
